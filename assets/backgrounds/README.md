# Background Assets

- `main-menu-battle-bg.webp`：Gimmy 提供的三國守方對僵屍戰場背景，已壓縮成 WebP，作為主選單大廳背景。
- `level-1-day-camp.webp`：Gimmy 提供的第一關日間三國軍營背景，作為第一關關卡卡片與遊戲棋盤背景。
- `level-2-night-siege.webp`：Gimmy 提供的第二關夜間僵屍攻城背景，作為第二關關卡卡片與遊戲棋盤背景。

主選單使用深色漸層遮罩保留背景氣氛，同時讓按鈕與文字可讀。主選單目前精簡為三個入口：守城戰、進攻戰、能力圖鑑；右上角提供音樂/音效開關。

關卡選擇頁改用對應關卡背景縮圖：第一關日間軍營、第二關夜間攻城；遊戲棋盤也會依實際關卡切換背景。兩個關卡按鈕文字維持簡化為「第一關」「第二關」。
