# Character Assets

第五版「參考圖角色卡」風格：無背景 sprite、簡潔黑線、柔和手繪陰影、角色像卡片人物介紹中的獨立小角色。避免外接管過度設計；豌豆射手改成圓形豌豆嘴放在嘴巴位置。

## 植物
- peashooter.svg：圓頭豌豆射手，圓形豌豆嘴，無外接管。
- sunflower.svg：參考圖式向日葵，圓臉、花瓣、簡單笑臉。
- wallnut.svg：厚實直立堅果，半瞇眼、防守感。
- firepea.svg：火焰豌豆，紅色小身體、火焰頭、圓筒嘴。
- potato.svg：圓滾滾土豆雷，緊張大眼與芽。

## 僵屍
- normal.svg：瘦高灰綠普通僵屍。
- cone.svg：巨型交通錐帽、橘色背心、歪身跑。
- bucket.svg：巨型金屬桶帽、矮胖重裝、睏怒眼。
- football.svg：紅色護具、衝刺姿勢。
- pea-zombie.svg：灰綠僵屍頭與小豌豆嘴。
- pole-vault.svg：長桿與跳躍姿勢。
