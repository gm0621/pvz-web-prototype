# 角色素材清單

這批素材是第三版「無背景 Q 版可愛角色」SVG，根據 Gimmy 確認的方向重製。

- 規格：`viewBox="0 0 1024 1024"`，高解析度、可無損縮放。
- 背景：無場景背景，只保留角色與透明底，適合放進遊戲棋盤。
- 風格：大頭小身體、粗黑外框、圓臉大眼、乾淨高彩度、手遊角色感。
- 動感：SVG 內含 CSS bob/run/blink/shine 動畫。
- 原創：避免直接複製既有 IP，只保留塔防角色辨識元素。
