# 角色素材清單

這批素材是第二版高解析度原創卡通塔防風格 SVG。

- 規格：`viewBox="0 0 256 256"`，可無損縮放。
- 質感：每張都有漸層背景、邊框高光、陰影濾鏡、角色細節與高光。
- 動感：SVG 內含 CSS idle/run/blink/shine 動畫，替代 GIF 達到輕量動態效果。
- 風格：避免直接複製既有 IP，美術方向為原創可愛塔防角色。

- sunflower.svg：向日葵，太陽花瓣與發光核心。

- potato.svg：土豆雷，爆炸警示燈與地雷感。
