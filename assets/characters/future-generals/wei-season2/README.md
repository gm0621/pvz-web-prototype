# 第二季魏國角色介紹

此批僅用於「角色介紹」的獨立魏國頁籤，不加入第一季出戰、AI、解鎖、角色等級、商城或雲端存檔。既有守方圖鑑頁籤稱為「蜀國」，僵屍方保持獨立。

## 圖片處理

從專案根目錄執行 `python3 -B scripts/prepare_wei_guide_assets.py`（需 Pillow），重製 1024×1024 透明 WebP。
沿用既有 `normalize`，仅對 RGB 原圖移除邊緣連通的黑色背景；保留已存在的透明度、原圖姿勢及「魏」字方向，不鏡像、不裁掉武器或旗幟。

## 介紹資料

`js/wei-guide.js` 為獨立、僅供展示的角色資料及渲染器，包含普通行動、固定天賦、機率技能、設計限制。小兵以固定天賦為主，未虛構機率大招。費用、HP、範圍數值、冷卻、技能機率及解鎖順序未定案，不顯示可出戰或可升級資訊。

`tests/wei-guide.spec.js` 驗證桌機／手機頁籤切換、全部角色圖片及詳情、版面寬度、返回蜀國詳情狀態，以及瀏覽魏國前後既有戰鬥／進度資料不變。
