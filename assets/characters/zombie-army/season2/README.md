# 第二季・破陣屍軍：角色介紹

本批最初以圖鑑預告建立，目前 12 名第二季僵屍皆已透過 `js/season2-data.js` 納入第二季僵屍進攻十關、魏國守城敵軍、逐關解鎖與戰鬥數值。圖鑑入口為「角色圖鑑 → 僵屍方 → 第二季僵屍」，第一季名單與進度仍獨立保留；編輯介紹文案時仍以 `js/zombie-season2-guide.js` 為來源，不應直接改動第一季角色資料。

## 已確認圖片順序
1. 棺盾小屍 — 替後方擋箭的前排
2. 裂盾斧屍 — 專門拆盾的攻堅兵
3. 煙罐小屍 — 掩護屍群接近的輔助兵
4. 鉤鎖屍卒 — 把前排拉離軍陣
5. 縫屍醫官 — 讓舊僵屍撐得更久
6. 斷旗咒屍 — 暫時切斷支援的軍陣干擾者
7. 替身偶屍 — 打亂集火的誘餌兵
8. 陷城屍督 — 第二季關底頭目／全破獎勵候選
9. 鼠牙群屍 — 低成本、靠同伴圍攻的基本兵
10. 腐釘弩屍 — 替近戰隊友製造傷口的遠程兵
11. 毒囊噴屍 — 處理密集守軍的持續傷害兵
12. 破門撞屍 — 把推進距離轉成第一擊威力

原始 PNG 保存在 `source-originals/`，每張 SHA-256 記錄於 `manifest.json`。圖片保留原始朝左與旗字方向；鉤鎖屍卒、毒囊噴屍與破門撞屍原圖已有透明背景，保留噴液及碎石；其餘圖片移除邊緣連通白底，並依已檢視的來源座標清除繃帶／旗幟／武器封閉空隙中的白底。不得對整張圖片全域刪除亮色，以免損傷煙霧、繃帶與高光。

重製：`python3 -B scripts/prepare_zombie_season2_guide_assets.py`。輸出為 1024×1024 透明 WebP，保留邊界安全留白。

介紹及設計限制在 `js/zombie-season2-guide.js`；實際費用、生命值、攻擊節奏、冷卻、能力與逐關解鎖規則在 `js/season2-data.js`，詳細圖鑑會讀取同一套戰鬥資料。鼠牙群屍與腐釘弩屍為第一關初始角色，其餘角色依同模式第 1～10 關首次通關逐一解鎖；陷城屍督同時作為第十關頭目與全破後可用角色。現階段角色限第二季路線使用；跨季合流仍屬第四季規劃，尚未開放。

驗證：`npx playwright test tests/zombie-season2-guide.spec.js tests/wei-guide.spec.js`，以及 `npm run test`。視覺檢查須確認第一／二季、魏國及蜀國切換後，卡片、詳情標題、配色與攻擊範圍區域正確還原。
