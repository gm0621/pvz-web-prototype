# 八王之亂外傳：長安西行

第 167～172 關為可選番外。完成《洛陽風雲》第 166 關後，尾聲返回主選單，玩家可以自行進入《長安西行》。曾完成第 166 關的存檔也能直接進入。第 142 關是主篇結局。

| 關卡 | 行軍圖 | 任務與史實 |
| --- | --- | --- |
| 167 洛陽清點 | 洛陽宮城 | 整理傷員名冊、糧冊和公文。司馬乂遇害後，司馬穎入洛接掌朝政，接著返回鄴城。 |
| 168 鄴城傳詔 | 鄴城 → 洛陽宮城 | 接應三隊使者，行軍圖用信封代表詔令。羊獻容、司馬覃被廢，司馬穎成為皇太弟。 |
| 169 河橋護駕 | 洛陽宮城 → 河橋 | 沿出城路口、河畔驛站、河橋營地分三批護送補給。護衛回到同一路後，糧車會從原地繼續。司馬越等人奉晉惠帝北上，嵇紹隨行。 |
| 170 蕩陰撤離 | 河橋 → 蕩陰 | 第三波追兵出現後按「全軍撤離」，保住至少一隊並讓所有存活友軍回到左側。石超在蕩陰打敗北上軍隊，嵇紹護駕遇害，惠帝被帶到鄴城。 |
| 171 鄴城返洛 | 鄴城 → 洛陽 | 接應三隊先行報信的使者。王浚和司馬騰進逼鄴城，司馬穎帶惠帝回到洛陽。 |
| 172 長安西行 | 洛陽 → 長安 | 依序護送三批糧車經西行路口、途中驛站、長安城門。護衛回到這一路後，糧車會從原地繼續。張方迫使晉惠帝、司馬穎前往長安。通關後回主選單，可以重玩。 |

六關都在 304 年。行軍圖以地名和方向呈現主要行程，河橋標記代表北上的黃河渡路。整備、使者、軍糧、撤離隊及營地對話為遊戲改編。蕩陰關卡完成代表接應隊撤回，惠帝與嵇紹的史實結果由戰後劇情交代。
