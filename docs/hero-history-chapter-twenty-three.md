# 第二十三章 成都餘波

第 131～136 關接續成都受降。年份採史書紀年對照，末關以魏咸熙二年、晉泰始元年（265 年）標示。西晉建立時東吳仍在，章末保留後續時間線。

| 關卡 | 行軍圖或交接地 | 玩法與史實結果 |
| --- | --- | --- |
| 131 涪城繳兵 | 郪縣 → 涪縣，標示鍾會受降 | 接應三隊傳令使者。姜維奉劉禪的命令向鍾會投降。 |
| 132 鄧艾被徵 | 成都交接地，標示衛瓘與鄧艾 | 整備詔令、車馬與名冊。魏廷下令收押鄧艾，由衛瓘執行。 |
| 133 成都閉署 | 涪縣 → 成都，標示遭扣的魏將胡烈 | 接應三隊使者。鍾會反抗魏廷，將部分魏將扣在府署，消息傳到軍營。 |
| 134 成都亂起 | 成都府署 → 成都街巷，區域示意 | 撐到接應完成，讓在場的存活友軍撤到左側。鍾會、姜維死於兵變，蜀漢未復國。 |
| 135 安樂公入洛 | 成都 → 洛陽，省略中途站 | 送出三批路上補給。劉禪遷往洛陽，受封安樂公，郤正隨行。 |
| 136 洛陽建晉 | 洛陽受禪地 | 整備冊書、禮壇及公告。司馬炎接受魏帝讓位，建立西晉。 |

只有第 134 關出現敵波，以保全護送隊伍結算。史書確定鍾會、姜維死於兵變，姜維意圖復蜀則在遊戲裡注明是裴松之引述的史料。任務細節、城中撤離示意和營地對話屬改編。第 132、133、136 關沿用魏方選將與個別強化，其他關卡沿用原本的蜀方武將設定。兵卡是遊戲搭配，歷史人物由劇情、行軍圖、營地和圖鑑各自呈現。
