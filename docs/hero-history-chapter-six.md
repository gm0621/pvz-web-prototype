# 第六章：迎駕與下邳（第 29～34 關）

接續第五章定陶之戰，使用曹操／夏侯惇／曹洪的既有兵卡、技能與裝備欄位。每關包含序幕、戰前後對話、史實／改編小檔案、問答、行軍圖、人物圖像與營地談話。

| 關卡 | 年代與史實骨架 | 遊戲任務與界線 |
| --- | --- | --- |
| 29 洛陽接駕 | 196 年漢獻帝回洛陽，曹操迎天子，後遷許 | 三路接應使者；皇帝不作戰鬥單位，敵方匿名游兵為道路遭遇改編 |
| 30 許縣屯田 | 196 年推行屯田，棗祗、韓浩等參與 | 備妥三輛糧車；把長期耕作壓縮成補給任務，不暗示幾秒收成 |
| 31 宛城退路 | 197 年張繡反擊，曹操敗退；典韋、曹昂、曹安民遇害 | 張繡長槍牽制預警後鉤擊；敵將出場後滿 18 戰鬥秒可撤，曹操與曹洪存活、所有在場友軍退回左側才成功。敵將保留生命；曹洪護衛為統一玩法改編，不抹去遇害者 |
| 32 陳地迎敵 | 197 年袁術稱帝、侵陳後撤，橋蕤等留守迎戰被斬 | 橋蕤「軍旗催陣」支援敵軍；不把袁術寫成此役被殺 |
| 33 下邳合圍 | 198 年曹操攻呂布，郭嘉、荀攸參與計策 | 三路安全累計 24 戰鬥秒，受阻保留進度、暫停凍結，仍須清完敵軍；圍城與決水只由文字解說，承認對居民的傷害，不以傷害平民作獎勵 |
| 34 白門樓前 | 建安三年下邳結局，呂布、陳宮被俘，後被處死 | 呂布方天破陣預警與鉤擊；生命歸零轉「被俘」呈現，不提前顯示被斬或沿用定陶撤走，不安排虛構史實單挑。處死僅由結局文字交代 |

採史書建安三年的紀年順序標示 198；歲末事件與公曆換算可能跨至 199，不將現代日曆日期當成確定值。

## 行軍、存檔與結算

章內概覽：定陶 → 洛陽 → 許縣 → 宛城 → 許縣 → 陳地 → 許縣 → 下邳。這是事件間的示意連線，不是考證後的精確道路。陳地與下邳之前明示回許整軍；中間沒有做成關卡的戰事在改編說明中交代。第 34 關為下邳當地推進，不畫成重複跨城。

本章為第 29～34 關，目前完整遊戲為 64 關；舊 28 關進度直接接第 29 關，軍資、行囊與各軍獨立兵器強化保留。曹操軍讀取 `armyWeapons.cao`，不繼承孫堅軍或劉備軍的強化。每關首勝 80、重玩 0；第 28 關尾聲後接新章，第 34 關尾聲接第 35 關「許都整軍」。沿用本機存檔格式，不動原殭屍遊戲。
