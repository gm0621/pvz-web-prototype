# 詳細圖鑑 v2：發布與回復

## 範圍

- 新增唯讀圖鑑資料適配器、共用詳細頁、SVG 範圍圖與隔離教學分鏡。
- 以實際角色定義和 effectiveUnit 讀出生命、普攻、費用等數值；技能條件另按引擎逐項整理。
- 第一季蜀國／僵屍、第二季魏國／僵屍與召喚物共用結構。
- 魏國新武將的數字為候選，不寫入戰鬥字典、名冊、商城或存檔。未定案僵屍明示待定。
- 不修改戰鬥邏輯、關卡、解鎖、SQL、雲端 RPC、角色圖片。工作區既存的 `supabase/sgz_profiles.sql` 修改不在本次發布內。

## 示範界線

教學是五段分鏡，不是另外一套完整戰鬥引擎。分鏡呈現條件檢查、動作、已知數值變化及限制；機率成功採教學指定，不呼叫實戰亂數或觸發真實戰鬥。控制／光環／尚未定案狀態以概念標記與精確文字說明，不宣称已模擬全部敵人 AI、控制抗性或多單位傷害傳播。

動畫播放不寫 localStorage／玩家資料，不消耗真實資源。切招式、換角、關閉、背景頁會停止計時；減少動態效果偏好時改為逐步操作。

## 可重跑檢查

1. `node --check js/guide-v2-data.js`、`node --check js/guide-v2.js`。
2. `npm run test -- tests/guide-v2.spec.js tests/wei-guide.spec.js tests/zombie-season2-guide.spec.js --workers=1`。
   - 全角色／全招式分鏡遍歷、無無效數值。
   - 前後 profile、localStorage、戰鬥定義與名冊完全相同。
   - 魏國長戟攔截成功與條件未達、魏國新武將預覽、趙雲近遠程、左右方向、召喚物連結、陣營切換與手機寬度。
3. 桌面與手機實際截圖，檢查棋盤、傷害、數值、按鈕与文字；關閉按鈕在捲動後仍可點擊。
4. 最後執行 `npm run test`。若測試 HTTP 伺服器在並行請求下重設連線，需保留失敗證據，修正本機服務或改單 worker 重跑，不能把資源未載入當成遊戲正常。
5. 明確 stage 本次檔案，檢查 staged diff，再 commit／push。
6. 取得 Pages 上 index、app、wei-guide、兩個新 JS、一個新 CSS 的位元組；與 commit 檔案逐一比對 SHA-256。
7. 在隔離瀏覽器執行正式站主選單 → 圖鑑 → 魏國 → 長戟天賦 → 逐步結算、未達條件分支、夏侯惇概念技能、蜀國與僵屍切換；檢查 console 與圖像。

## 回復

本次無資料庫 migration，無玩家資料格式變更。出現回歸時以本次發布 commit 執行 `git revert <release-commit>`，再 push main；等待 Pages 生效並比對舊版資源。不要重置或刪除玩家存檔，不要連帶回復工作區不相關 SQL。
