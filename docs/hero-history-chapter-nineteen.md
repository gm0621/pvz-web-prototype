# 第十九章「興勢守漢中」

接續第 106 關五丈原歸途。從 234 年撤軍爭端講到 244 年興勢之戰，保留蜀漢軍的三路玩法、營地及既有養成。

| 關卡 | 史實與行軍圖 | 過關任務 |
| --- | --- | --- |
| 107 棧道爭路 | 234 年，斜谷 → 南谷口一帶。回看同一次撤軍中的蜀軍內部爭端，王平阻止魏延，魏延後被馬岱追殺。 | 接應三隊傳令使者。 |
| 108 成都接任 | 234 年，成都。五丈原的消息傳回朝廷。劉禪任命蔣琬為尚書令。 | 整備案卷、糧冊、驛站。 |
| 109 漢中整軍 | 238 年，成都 → 沔陽。蔣琬、姜維進駐漢中，王平任前護軍。 | 依預警守住上、下、中三路的三波來敵；清完三波且防線未失守。 |
| 110 涪城轉運 | 243 年，沔陽 → 涪縣。蔣琬移駐涪縣，費禕任大將軍，王平統領漢中守軍。 | 依序護送糧車走山路口、接應站與涪縣營地。護衛回到同一路可從原地續走，三批送完後清退餘兵。 |
| 111 興勢守關 | 244 年，南鄭 → 興勢一帶。曹爽由駱谷來攻，王平派人守關，自己在後接應。 | 依預警守住上、下、中三路的三波來敵；清完三波且防線未失守。 |
| 112 援軍解圍 | 244 年，成都 → 興勢一帶。涪縣與成都的援軍相繼抵達，曹爽因攻勢受阻和運糧困難退兵。 | 接應三隊使者，確認各營收到援軍抵達的消息。 |

地圖標的是歷史區域與行進方向。第 107 關依《魏延傳》正文，史書注文另有不同記載。第 112 關地圖顯示成都援軍方向，曹爽列於對手欄，保留撤回魏國的結局。三路任務、兵卡和營地對話為遊戲改編。
