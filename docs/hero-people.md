# 人物圖鑑

入口 `/hero/people.html`，首頁、戰前序幕與營地另開分頁，讀完切回原遊戲。圖鑑不讀寫存檔、不解鎖關卡、不發軍資。

目前收錄 55 位：48 位史實人物、2 位演義人物、5 位遊戲原創（虛構人物）。每張卡片有遊戲造型、一句話標題、短介紹、可展開的記憶小提示、史實／改編提醒與出場或被提到的關卡。人物圖不是歷史照片；比喻不是原話；關卡列表只是查詢，不能藉此跳關。卡片可能提到後續劇情，入口已有提醒。

曹仁、夏侯淵已加入第 25／28／29／30 關相關敘事；子孝、子廉、妙才、元讓可分別找到曹仁、曹洪、夏侯淵、夏侯惇。圖像、來源與改編範圍見 [人物擴充紀錄](hero-cao-companions.md)。

姓名／別名／線索即時搜尋，完整姓名或別名優先列出，再顯示內容提及者。可依三種類型篩選，清除會重設查詢與分類。盧公對應盧植，劉協對應漢獻帝；荀彧與荀攸、袁術與袁紹等易混淆處用短句說明。

資料在 `hero/people-data.mjs`，圖像沿用人物資料與軍隊圖集；登場關卡由實際顯示的劇情、序幕、歷史小札、小問答、營地與該關兵卡計算；史料連結標題不算劇情登場。歷史章使用該關史實／改編文字，不誤算未顯示的共用章節背景。未在已發布關卡出場的延伸人物會明示。搜尋與顯示以 `textContent` 組合，不將輸入當 HTML。

手機一欄、平板兩欄、大螢幕三欄；控制至少 44px，內文以短段落呈現，細節預設收合。測試見 `tests/hero-people.spec.js` 及 `tests/unit/hero-people.cjs`。新圖集及生成提示見 [第六章美術紀錄](hero-chapter-six-art.md)。
