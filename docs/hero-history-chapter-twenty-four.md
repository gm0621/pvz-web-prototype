# 第二十四章 西晉一統

第 137～142 關承接司馬炎建立西晉，從 269 年的襄陽屯田走到 280 年東吳投降。兩場西陵戰事由不同陣營呈現，戰後結局依各自年份。

| 關卡 | 行軍圖或接任地 | 任務與史實 |
| --- | --- | --- |
| 137 襄陽屯田 | 洛陽 → 襄陽，示意從任命到駐地 | 整備田地、水渠、糧倉。羊祜在荊州屯田存糧，晉、吳繼續相持。 |
| 138 西陵守圍 | 樂鄉 → 西陵。羊祜註明另一路往江陵 | 吳軍按預警擋住三波，清退餘兵並至少保住一道防線。陸抗收回反叛者據守的西陵，晉援軍撤退。 |
| 139 襄陽交印 | 襄陽接任地，羊祜以舉薦者身分出現 | 接應三隊使者。278 年羊祜去世，杜預接掌荊州。 |
| 140 益州備舟 | 益州備舟地 | 護送三批軍糧到備舟碼頭。主航道封航時可改走岸邊，已送達的批次與當前航程會保留。279 年西晉分路出兵，王濬負責上游水軍。 |
| 141 西陵順流 | 永安 → 西陵，示意長江上游路段 | 派友軍護送主船，主航道封航時可改走岸邊，抵達後清退剩餘巡江敵船。280 年王濬率船隊攻下西陵等地，杜預另從荊州進軍江陵。 |
| 142 孫皓受降 | 武昌 → 石頭城，標示孫皓請降 | 整備降書、印綬、城門。孫皓向王濬投降，東吳滅亡。 |

第 138 關沿用吳方隊伍與兵器存檔，其餘沿用可選將的隊伍及獨立兵器存檔。兵卡、整備任務和營地對話屬改編。行軍圖畫出每關的地理方向，圖上的路段省略沿途站點。
