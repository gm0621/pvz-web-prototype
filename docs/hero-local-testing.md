# 電腦本機跳關測試

## 線上測試（免安裝）

使用者要求另提供可直接開啟的網址：
https://gm0621.github.io/pvz-web-prototype/hero/test.html

選關、等級、劇情／開戰／營地後按「開始測試」；F8 或「測試 · 換關」可重新選擇。線上工具使用 `heroLegendOnlineTest_v1`，不讀寫正式進度。重新整理指定測試網址會重建測試進度；可複製網址重現關卡與等級。一般遊戲不顯示測試連結，但知道網址的人仍能用，沒有管理者身分驗證。

`test.html` 載入當前正式 index，`test-loader.mjs` 只在測試頁改用測試存檔並接上共用 hook；相對模組網址轉成正式來源的絕對網址。沒有複製整份引擎，遊戲更新即同步；入口標記不符會停止並顯示錯誤。hook 修改時需同時驗證本機與線上入口。

下列本機工具仍可離線開發使用，不是正式網站的管理者登入。

## 開啟

macOS 在專案資料夾雙擊 `啟動英雄測試.command`；保持開啟的終端機視窗即可。需要 Python 3.9 以上，不需安裝 npm 套件。

亦可在專案根目錄執行：

```sh
python3 tools/hero-test-server.py --open
```

網址：<http://127.0.0.1:4188/hero/>。停止服務：在啟動服務的終端機按 Ctrl+C。若連接埠已被使用，可先關閉舊服務，或加 `--port 4190` 改用另一個埠。

## 測試操作

- 選第 1～112 關，列表含關名與敵將。
- 選全部武將 Lv.1～10；仍沿用正常技能解鎖、MP、冷卻、傷害與任務規則。
- 可直接開戰、從戰前劇情開始，或直接到戰後營地。曹操軍直接開戰仍會顯示正常選將畫面。
- 預設略過初次技能介紹；勾選後可測出場介紹。
- 畫面中的「測試 · 換關」（或 F8）可再次選關，開啟時暫停戰鬥，取消後恢復原暫停狀態。若遊戲已有對話視窗，先關閉該視窗再換關。
- 開始測試／重新整理指定測試網址都會建立新的測試進度，前面關卡視為已完成，軍資 200，兵器未強化。這是可重現的起始條件，不是無敵模式。

## 存檔與範圍

本機工具在傳送 app.mjs 時才注入面板與獨立存檔鍵 `heroLegendLocalTest_v1`。磁碟上的正式 app.mjs 不變，正常 `heroLegendProgress_v1` 不讀寫。僅監聽 127.0.0.1，拒絕外部 Host，也不提供專案其他檔案路徑。此限制是本機服務範圍，不是防止玩家自行修改公開前端的安全機制。

遇到 bug，記錄關卡、等級、進入方式、操作步驟；網址中的測試參數也可複製。若遊戲程式變更導致注入標記不符，服務會拒絕傳送 app.mjs，應更新工具，不可改成讀寫正式存檔。

驗證：`node node_modules/@playwright/test/cli.js test --config=playwright.hero-local-test.config.js`。
