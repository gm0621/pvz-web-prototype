# 第二十章「姜維北伐」

接續第 112 關興勢解圍，沿 246～255 年的史事，從費禕主持政務走到姜維北伐與狄道解圍。本章沿用蜀漢軍的三路玩法、選將與養成、首勝軍資及戰後營地。

| 關卡 | 史實與行軍圖 | 過關任務 |
| --- | --- | --- |
| 113 涪城新訊 | 246 年，成都。蔣琬在冬天病逝，已任大將軍的費禕繼續主持政務。 | 整備糧冊、驛站、營簿。 |
| 114 洮西接應 | 247 年，沔陽 → 洮西。姜維與郭淮、夏侯霸交戰，接應投向蜀漢的部眾。 | 接回三隊使者。 |
| 115 陰平迎將 | 249 年，陰平 → 沔陽方向。曹爽遭誅後，夏侯霸投奔蜀漢，裴松之注引《魏略》記其途中迷路缺糧。 | 護送三批糧車。 |
| 116 漢壽新訊 | 253 年，漢壽。費禕在新年聚會上遇害，結算及營地接到姜維出兵。 | 接應三隊傳令使者。 |
| 117 南安糧盡 | 253 年，沔陽 → 南安。陳泰率援軍抵達洛門，姜維糧盡撤出，南安仍屬魏國。 | 第三波追兵出現才可撤離；至少保住一隊，所有在場友軍回到左側才過關。 |
| 118 洮西收兵 | 255 年，洮西 → 狄道 → 鍾題。王經在洮西敗後退入狄道，陳泰解圍，姜維退駐鍾題。 | 帶回狄道前線的隊伍，至少有一隊友軍存活，所有存活的武將與士兵都撤到左側。 |

行軍圖呈現區域和方向，沔陽是接應營地的示意，鍾題以位置示意呈現。陳泰和王經出現在相關人物欄，戰場撤離保留南安與狄道仍由魏軍控制的結局。三路任務、隊伍和營地對話為遊戲改編。
