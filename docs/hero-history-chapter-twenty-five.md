# 第二十五章 太康之後

第 143～148 關承接孫皓在石頭城投降，從 280 年西晉進入太康年間，接到晉惠帝即位與 291 年洛陽兩次政變。本章收在八王之亂的初期。

| 關卡 | 行軍圖或交接地 | 任務與史實 |
| --- | --- | --- |
| 143 孫皓入洛 | 石頭城 → 洛陽，標示司馬炎接見 | 送三批隨行補給。孫皓被送往洛陽，受封歸命侯。 |
| 144 太康裁兵 | 洛陽議事地 | 整理軍籍、歸鄉文書與州郡簿。朝廷裁減州郡兵力，地方留下部分治安人員。 |
| 145 惠帝即位 | 洛陽宮城，標示楊駿輔政 | 接應三隊使者。290 年，司馬炎去世，司馬衷即位。 |
| 146 楊駿之變 | 洛陽宮城 → 洛陽街巷，遊戲護送路線 | 各路累積守備 24 秒並清退場上亂兵。賈皇后等人發動政變，楊駿被殺。 |
| 147 汝南王入朝 | 許昌 → 洛陽，標示衛瓘共同輔政 | 整備印信、公文與名冊。司馬亮由許昌入朝，和衛瓘共同輔佐惠帝。 |
| 148 洛陽再變 | 洛陽街巷 → 洛陽城門，遊戲撤離路線 | 按「全軍撤離」，讓存活友軍退回左側。司馬亮、衛瓘遇害，司馬瑋隨後被處死。 |

第 143 關隨行隊沿用吳方三路隊伍和獨立的兵器存檔。其餘關卡沿用西晉篇的選將與裝備。第 146、148 關有敵波，其他四關以文書、傳令或運糧呈現。城內路線、任務、兵卡、營地對話都是遊戲改編。
