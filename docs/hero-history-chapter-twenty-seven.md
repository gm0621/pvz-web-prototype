# 第二十七章 諸王討趙

第 155～160 關接續趙王篡位，沿 301 年的許昌起兵、兩路戰事、惠帝復位、齊王掌權前進。齊王、成都王是宗室封號，這時司馬冏鎮守許昌，司馬穎駐於鄴城。第 155 關由信封標記沿許昌到鄴城移動，司馬冏和司馬穎的頭像留在發信、響應的圖例。

| 關卡 | 行軍圖 | 任務與史實 |
| --- | --- | --- |
| 155 許昌傳檄 | 許昌 → 鄴城 | 接應三隊使者。司馬冏起兵，司馬穎從鄴城響應。河間王司馬顒先助趙，後改支持兩王。 |
| 156 潁陰守營 | 許昌 → 潁陰 | 各路累積守備 24 秒，再清退最後一波。張泓先在陽翟一帶取勝，進逼潁陰，遇到齊王反擊後退兵。 |
| 157 黃橋收兵 | 鄴城 → 黃橋 | 至少保住一隊，存活友軍全回左側。成都王前鋒敗於趙王軍，盧志等人勸司馬穎重整兵力再戰。 |
| 158 湨水反擊 | 黃橋 → 湨水 | 守住渡路累積 24 秒，再清退敵波。成都王在湨水反擊得勝，趙王軍敗退，成都王軍渡過黃河。 |
| 159 惠帝復位 | 金墉城 → 洛陽宮城 | 接應三隊使者。王輿等人入宮，孫秀被殺，惠帝回宮復位，司馬倫後被賜死。 |
| 160 齊王輔政 | 許昌 → 洛陽 | 整備印信、名冊、公文。司馬冏入洛任大司馬，惠帝仍在位，司馬穎辭別回鄴城。 |

潁陰、黃橋和湨水的事件分序採《資治通鑑》卷八十四。陽翟戰事與惠帝復位一併參照《晉書》。行軍圖表示地點與方位，黃橋採戰區示意。對話、兵卡、撤離、守備秒數和接應批數是遊戲改編。沿用西晉篇選將、兵器、軍資與存檔。
