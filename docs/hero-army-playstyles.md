# 三軍玩法與武將特色

## 已實裝

所有軍隊共用救援、設伏、突擊，特色是強項，不是互斥限制。既有單挑的對象、觸發條件、二打一及歷史撤退／俘虜結局保持原設計。

- 劉備軍：同袍救援 55 護盾，單挑結束 +30 軍勢並給全軍 25 護盾。
- 曹操軍：每戰鬥秒 +1.4 軍勢，伏兵待命 14 秒。
- 孫堅軍：擊破敵軍 +6 軍勢；武將首次抵達每路 x≥0.65，+15 軍勢並給其他路 20 護盾；全軍突擊 8 秒。
- 其他軍隊基準：每秒 +1、擊破 +3、單挑後 +20、救援 35 護盾、伏兵 9 秒、突擊 5 秒。逃出城門的敵軍不給擊破獎勵。
- 每場軍勢從 40 開始，上限 100；戰術共用 8 秒冷卻。戰鬥的暫停／過場／單挑不推進軍勢與戰術時間。軍勢不寫入存檔。
- 救援花費 35；設伏 40；突擊 60。伏兵布在所選路友軍最前方再往前 0.16，敵人進入後暈眩 1.5 秒，普通攻擊降低 30% 持續 6 秒。突擊傷害 +20%，不覆蓋玩家駐守或撤退命令。
- 入口：更多 → 戰術（T）；鍵盤 T 可直接開關。資訊在抽屜，戰場不縮小，伏兵位置有「伏」標記。

12 人施放有效技能後追加特色連動，不另扣 MP，仍受原招式冷卻、等級、射程與目標限制：

| 武將 | 特色 |
|---|---|
| 劉備 | 最危急同袍 20 護盾 |
| 關羽 | 近敵暴露弱點 4 秒，後續傷害 +20% |
| 張飛 | 打斷近敵普通蓄力、暈眩至少 1 秒，不取消劇情大將招式 |
| 曹操 | 軍勢 +8 |
| 夏侯惇 | 自身 25 護盾 |
| 曹洪 | 最危急同袍 25 護盾 |
| 曹仁 | 同路友軍至少 25 護盾 |
| 夏侯淵 | 壓制同路射程內最靠近城門的普通敵兵 1.5 秒 |
| 于禁 | 打斷近敵普通蓄力並暈眩至少 1 秒 |
| 孫堅 | 軍勢 +8，配合前線突破與全軍突擊 |
| 程普 | 其他路最危急同袍 25 護盾 |
| 黃蓋 | 近敵破甲 4 秒，後續傷害 +20% |

護盾採較高值，不無限疊加；特色護盾至少持續 6 秒。保留既有技能、成長被動與兵種差異。一般技能數值說明指本體數值，額外連動在戰術面板顯示。

## 已定案、尚未實裝的登場設計

目前 64 關沒有可操作孫策、趙雲或諸葛亮；不為本次特色更新加入跨年代角色，也不宣稱以下已可玩。

- 孫策「小霸王」：正式登場關優先安排合理對手單挑；勝後鼓舞全軍並銜接突擊；重點關可連戰，但不可每波強制中斷。歷史上不能戰勝或斬殺的對手保持原結局。
- 諸葛亮：蜀軍保留完整策略玩法，突出選路設陣、誘敵與連環伏兵；不能因屬蜀軍就限制軍師計策。
- 趙雲：移動穿插、跨路救援及護送撤離。
- 魏、吳遇適合武將與關卡仍保留單挑；陣營只影響強項，武將與劇情決定具體體驗。

尚需新章節、人物素材與出場流程接入，並另做新角色及自然通關平衡驗證。
