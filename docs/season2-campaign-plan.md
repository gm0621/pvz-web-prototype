# 第二季「北境鐵壁」— 關卡設計與製圖交接

> **第二季 1～10 關設計定稿；目前僅第 1～2 關已開放遊玩，第 3～10 關尚待戰鬥實裝。** 此文件由 `node scripts/export_season2_plan.cjs` 產生，資料來源為 `js/season2-plan-data.js`。定稿不代表數值平衡、自然通關或正式站部署已完成。

## 範圍與進度規則

- 共十處場景；魏國守城十關、僵屍進攻十關，各有獨立進度。圖片可由攻守共用，敵軍配置與教學目標不同。
- 第二季採魏國／第二季僵屍獨立出戰設計，第四季再跨季合流；共用角色身份與收集資料，不複製帳號。
- 每個模式初始 2 位角色；每關首次通關後取得 1 位，十關全破收齊該側 12 位。重玩不重複解鎖或發首次通關獎勵。
- 第二季卡片直接顯示；魏國守城與僵屍進攻都可各自從第一關開始。
- 同模式依序通關；已通關關卡可自由重玩，不能跨關解鎖。
- 每關首次通關後取得一位本方角色；當關首次挑戰不能使用該獎勵。
- 曹操與陷城屍督於各自第十關通關後取得，只供重玩與後續季度使用。
- 預覽所有關卡不表示已解鎖。此頁沒有通關模擬、資源寫入、雲端 RPC 或可啟動的第二季戰鬥。
- 實裝時須獨立儲存 season / mode 進度；前端入口、部署卡、AI、match-start 與獎勵 RPC 一致驗證。禁止把本設計案直接塞入第一季 LEVELS 或以假存檔全開。

## 初始角色

- 守城：屯田兵、強弩兵。
- 進攻：鼠牙群屍、腐釘弩屍。腦力沿用自動補給概念，不依賴尚不存在的經濟兵。

## 主線與三幕推進

- **危機起點：**第一季北運棺車上的役魂紋一路指向魏境。屍軍不是漫無目的襲擊，而是在測量北境補給線、拆解軍陣，準備奪取能號令守軍與亡魂的中軍旗臺。
- **魏國守城目標：**魏軍從臨時前哨一路後撤整軍，在補給線未斷前辨認屍軍戰法，最後於北境主城以完整軍陣守住中軍旗臺。
- **僵屍進攻目標：**僵屍方沿同一條戰線試探、拆盾、拉陣、斷援，逐步組成真正攻城隊；此路線是另一種可能，不推翻守城結局。
- **第 1–3 關｜外圍試探：**屍軍測量前哨、營門與軍道；玩家學會補給、盾弩軍陣與破盾／攔截。
- **第 4–7 關｜軍需爭奪：**戰線進入糧倉、斷橋、兵坊與烽臺；雙方開始拉扯、治療、誘餌與集火協同。
- **第 8–10 關｜中軍決戰：**屍軍以斷旗與破門隊逼近中軍；魏軍以破甲、封策與蓄謀反制，最終在北境鐵壁決戰。
- **季末銜接：**守城結局由曹操接掌整軍，確認役魂紋背後仍有更大的操旗者；攻城結局則由陷城屍督奪下旗臺，留下第四季跨陣營會戰的危機。兩條結局不把第三季吳國水戰提前混入。

## 共通製圖規格

- 16:9 橫圖，建議 1920×1080 或更高解析度；無關卡字、UI、按鈕與人物大頭。
- 北境軍營／要塞：深藍、鐵灰、冷白為主，局部暖金或爐火。避免沿用第一季綠草坪；河道、船與水路保留給吳國。
- 重要建物留在中央安全區，邊緣預留裁切空間；明亮與細節集中遠景，前景簡潔。
- 已提供選關圖片：第 1 關「霜土前哨」、第 2 關「石壘營門」、第 3 關「拒馬長道」、第 4 關「風沙糧倉」、第 5 關「乾谷斷橋」、第 6 關「鐵爐兵坊」、第 7 關「烽臺夜哨」、第 8 關「霜骨古道」、第 9 關「魏武中軍」、第 10 關「北境鐵壁」。尚未提供的關卡維持 `cardArt:null` 與 CSS 場景示意，不請求不存在的圖片。
- 收到圖片後保留原圖並轉 WebP，設定對應 stage.cardArt，例如 `assets/backgrounds/season2/s2-01.webp`。載入失敗仍顯示佔位。
- 這批圖是選關卡片。未來戰鬥盤面另做可讀性設計，不直接把橋洞、拒馬或風沙變成隨機封格、遮擋、扣血與滑動規則。

## 波次短劇情與提前軍情

- 每關每個模式都採「準備期情報 → 主波戰術變化 → 領隊／頭目到達」三段短劇情；不開阻塞戰鬥的大視窗。
- 軍情在大波抵達前顯示並保留可讀的波數、倒數與威脅類型；略過台詞不會移除戰術情報。
- 只預告排程已確定的敵軍數量、路線或能力；若兵種仍由出兵當下隨機決定，就只能預告「多路／重兵／支援」，不可假報特定兵種。
- 波次對話不改兵力、資源、冷卻或獎勵；暫停與續玩必須保存已播放進度，不能重複發放增援資源。

## 各關設計與圖片說明

### 01｜霜土前哨 — 外圍防區

**製圖／冷白清晨：**灰白霜土、低矮木柵、遠處北境丘陵與少量靛藍魏旗。小型前哨，不是大城堡；保留清楚的平坦前景，不畫綠草坪。
建議檔名：`s2-01.webp`

**魏國守城**
北境第一班哨兵發現屍群踏過霜土。屯田兵先建立補給，強弩兵逐路迎擊，守住尚未築好的防線。

- 重點：學會後勤與分路配置；先用少量、錯開出現的敵人建立節奏。
- 波次短劇情：1. 哨兵回報霜土腳印分成多路。 → 2. 腐釘弩屍進入射程，弩手要求分路校射。 → 3. 插滿箭的棺板逼近，前哨迎戰第一名領隊。
- 首次挑戰可用：屯田兵、強弩兵。
- 主要對手：鼠牙群屍、腐釘弩屍。
- 末段領隊：棺盾小屍。
- 通關後解鎖：大盾兵。
- 限制／反制：領隊最後單獨出場，沒有後排讓棺盾掩護；不要求尚未解鎖的破甲武將。

**僵屍進攻**
屍群先試探尚未成形的前哨。鼠牙群屍咬住前排，腐釘弩屍留下傷口，合力打開第一處缺口。

- 重點：學會近戰接手骨釘標記；從薄弱路線集中突破。
- 波次短劇情：1. 屍群看見木柵尚未合攏，先分路試探。 → 2. 腐釘留下第一處傷口，群屍收到集中撕咬的號令。 → 3. 強弩領隊鎖住缺口，最後一波必須換路或搶先壓制。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍。
- 主要對手：屯田兵、強弩兵。
- 末段領隊：強弩兵。
- 通關後解鎖：棺盾小屍。
- 限制／反制：守軍分批上場、沒有完整盾牆；基礎腦力自動補給，首關不依賴額外經濟角色。

### 02｜石壘營門 — 外圍防區

**製圖／陰天冷灰：**粗石堆砌的營門、木製橫樑、厚重石板路，兩側有破損旗架與箭孔。遠景是矮城壘，前景不用草地。
建議檔名：`s2-02.webp`

**魏國守城**
第一批盾兵趕到營門，棺盾屍群也開始掩護後排。魏軍必須讓大盾承傷，為強弩爭取校射時間。

- 重點：第一次建立盾在前、弩在後的同路軍陣。
- 波次短劇情：1. 營門回報棺板正掩護腐釘靠近。 → 2. 大盾列陣後，強弩收到集中射擊命令。 → 3. 裂盾斧聲撞上石門，守軍準備迎接破盾領隊。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵。
- 主要對手：鼠牙群屍、棺盾小屍、腐釘弩屍。
- 末段領隊：裂盾斧屍。
- 通關後解鎖：長戟兵。
- 限制／反制：裂盾領隊數量有限，搭配後排輸出而非只補盾；仍有可調整的空格。

**僵屍進攻**
石壘弩箭開始集中射擊。把剛取得的棺盾放在前方，掩護腐釘弩屍靠近，避開最厚的守備點。

- 重點：學會棺盾保護緊鄰後方；盾牌耐久不是無限資源。
- 波次短劇情：1. 屍兵發現石壘有一條尚未補齊的薄線。 → 2. 棺盾被令到前方承箭，腐釘在後準備開傷口。 → 3. 大盾領隊封住營門，屍群必須在棺板破裂前選定突破路。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍。
- 主要對手：強弩兵、屯田兵、大盾兵。
- 末段領隊：大盾兵。
- 通關後解鎖：裂盾斧屍。
- 限制／反制：大盾先少量登場、路線不全封；裂盾斧屍要通關後才取得，不能作為必需解法。

### 03｜拒馬長道 — 外圍防區

**製圖／風起午後：**延伸向遠方的灰褐軍道，道路外側交錯木拒馬、削尖木樁與破車輪。背景塵土低揚，五路前景仍完整平坦。
建議檔名：`s2-03.webp`

**魏國守城**
屍群沿長道加速推進，破門撞屍開始蓄勢。長戟兵接管缺口，讓衝擊停在軍陣前方。

- 重點：運用剛解鎖的長戟兵攔截突進，保留攔截冷卻。
- 波次短劇情：1. 遠哨看見長道盡頭的撞木開始加速。 → 2. 長戟兵報告攔截冷卻，守軍先處理伴隨的斧屍與腐釘。 → 3. 破門撞屍蓄滿衝勢，最後直線壓向缺口。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵、長戟兵。
- 主要對手：鼠牙群屍、裂盾斧屍、腐釘弩屍。
- 末段領隊：破門撞屍。
- 通關後解鎖：夏侯惇。
- 限制／反制：領隊只做可辨識的直線蓄勢，不跳到後勤身後；沒有強制封路地形。

**僵屍進攻**
魏軍把盾兵架在道路入口。裂盾斧屍先拆護盾，群屍與弩屍接續攻擊，不能只靠棺盾硬撐。

- 重點：第一次安排掩護、破盾、輸出的先後順序。
- 波次短劇情：1. 屍軍辨認出盾兵與長戟交錯的入口。 → 2. 裂盾斧先行開路，後隊等待盾勢削弱。 → 3. 長戟領隊封住長道，普通步兵必須正面拆陣而非假裝突進。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍。
- 主要對手：大盾兵、強弩兵、長戟兵。
- 末段領隊：長戟兵。
- 通關後解鎖：煙罐小屍。
- 限制／反制：玩家此時沒有突進單位，長戟不會額外壓制所有普通步行兵。

### 04｜風沙糧倉 — 軍需腹地

**製圖／砂金傍晚：**北地夯土糧倉、堆疊糧袋、棚架、半埋風沙的石板，暖金夕照配冷藍旗幟。風沙只做遠景氣氛，不遮滿畫面。
建議檔名：`s2-04.webp`

**魏國守城**
煙罐屍群趁風接近糧倉。夏侯惇守在煙霧出口，以近戰反擊接住第一波壓力，讓屯田兵繼續補給。

- 重點：遠程遇上煙霧減傷時，改用前排近戰接戰。
- 波次短劇情：1. 糧官聞到逆風飄來的屍煙，先撤開密集後勤。 → 2. 煙中斧屍接近，夏侯惇要求前排留出近戰接敵位置。 → 3. 鉤鏈越過煙幕，末段開始拉扯最前方守軍。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵、長戟兵、夏侯惇。
- 主要對手：鼠牙群屍、煙罐小屍、裂盾斧屍。
- 末段領隊：鉤鎖屍卒。
- 通關後解鎖：典韋。
- 限制／反制：鉤鎖最後少量登場，仍保留空格可重整；不讓風沙造成命中率隨機懲罰。

**僵屍進攻**
糧倉外的弩箭密度提高。煙罐小屍掩護隊伍接近，裂盾斧屍與群屍在近距離拆開防線。

- 重點：學會煙霧只減遠距直射傷害，不能無視近戰反擊。
- 波次短劇情：1. 煙罐開始順風鋪路，屍群等待弩線變暗。 → 2. 裂盾斧與群屍離開煙幕接戰，近戰反擊仍然有效。 → 3. 夏侯惇在糧倉口滿怒迎敵，最後一波不能只靠煙霧硬闖。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍、煙罐小屍。
- 主要對手：屯田兵、強弩兵、夏侯惇。
- 末段領隊：夏侯惇。
- 通關後解鎖：鉤鎖屍卒。
- 限制／反制：夏侯惇只守少數路線；新取得的煙罐不是近戰無敵盾，可轉向突破後勤較弱的一路。

### 05｜乾谷斷橋 — 軍需腹地

**製圖／峽谷斜光：**乾涸裂谷上的寬石橋，遠處有斷裂舊橋與峭壁。主戰線是完整橋面，不畫河水、船隻或棋盤破洞，水戰留給吳國。
建議檔名：`s2-05.webp`

**魏國守城**
鉤鎖越過橋面拉扯前排。典韋要守住身後弩兵，但整條防線也必須預留重整位置。

- 重點：理解緊鄰承傷與站位被拉開的差別。
- 波次短劇情：1. 橋頭哨報鉤鎖已瞄準最前排，軍陣先留一格重整空間。 → 2. 棺盾與腐釘接著上橋，典韋護住緊鄰後排。 → 3. 裂盾領隊趁陣形被拉開時逼近，守軍集中火力收口。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵、長戟兵、夏侯惇、典韋。
- 主要對手：鉤鎖屍卒、棺盾小屍、腐釘弩屍。
- 末段領隊：裂盾斧屍。
- 通關後解鎖：許褚。
- 限制／反制：許褚在本關通過後才解鎖；首次挑戰可用交錯站位與火力處理，不能要求免拉扯。

**僵屍進攻**
典韋在橋頭護住後排，正面硬打損耗太大。鉤鎖屍卒把前排拉離支援位置，再交給群屍集中攻擊。

- 重點：第一次以拉扯切開同路的前後排支援。
- 波次短劇情：1. 屍軍確認典韋只保護緊鄰後方的一人。 → 2. 鉤鎖等待合法空位，把最前排拉離護衛關係。 → 3. 典韋領隊親自守橋，最後衝線要避開完整護衛路。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍、煙罐小屍、鉤鎖屍卒。
- 主要對手：大盾兵、強弩兵、典韋。
- 末段領隊：典韋。
- 通關後解鎖：縫屍醫官。
- 限制／反制：只拉最前方目標且落點必須空著，不直接把後排軍師拖出；守方佈陣保留可拉的空間。

### 06｜鐵爐兵坊 — 軍需腹地

**製圖／爐火與鐵藍：**石造軍械工坊、熔爐暖光、鐵砧、兵器架與煤灰。不是燃燒中的城市；中央保持深灰石板，火光放兩側與遠景。
建議檔名：`s2-06.webp`

**魏國守城**
兵坊外的屍軍靠縫補維持戰力。許褚先卡住重兵，魏軍再集中弩火，避免各路零散傷害被補回。

- 重點：學會卡住威脅、逐個擊倒，而不是平均消耗所有敵人。
- 波次短劇情：1. 工匠回報受傷屍兵正在後方被重新縫合。 → 2. 許褚卡住重兵，弩隊改為逐個完成擊倒。 → 3. 破門撞屍從爐火外蓄勢，末段不能讓醫官持續補回。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵、長戟兵、夏侯惇、典韋、許褚。
- 主要對手：棺盾小屍、縫屍醫官、裂盾斧屍。
- 末段領隊：破門撞屍。
- 通關後解鎖：張遼。
- 限制／反制：醫官治療有空窗且不互補；張遼尚未取得，普通弩兵集中配置也必須能突破治療量。

**僵屍進攻**
許褚擋住通往兵坊的重點路線。縫屍醫官保住前排，腐釘與裂盾接力消耗，或選另一條較薄的防線。

- 重點：學會續戰與保護醫官，不讓醫官走到最前面。
- 波次短劇情：1. 醫官檢查前排傷勢，屍軍先選定需要續戰的主路。 → 2. 腐釘與裂盾輪流接戰，醫官保持在可治療但不貼臉的位置。 → 3. 許褚領隊鎮住兵坊入口，重兵路與薄弱路的取捨進入最後階段。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍、煙罐小屍、鉤鎖屍卒、縫屍醫官。
- 主要對手：大盾兵、長戟兵、許褚。
- 末段領隊：許褚。
- 通關後解鎖：毒囊噴屍。
- 限制／反制：許褚站穩後不易被拉扯；不要把上一關的鉤鎖變成萬用解法，也不全路堆滿許褚。

### 07｜烽臺夜哨 — 軍需腹地

**製圖／靛藍夜色：**高處石造烽火臺、城垛、冷月與稀疏橘色火盆。天空偏靛藍，剪影清楚；不用全黑或濃霧遮住角色。
建議檔名：`s2-07.webp`

**魏國守城**
草偶與毒液拖慢夜哨的判斷。張遼標記真正威脅，帶同路火力優先處理噴屍，避免把所有弩箭耗在誘餌上。

- 重點：分辨誘餌、持續傷害與真正需要集火的目標。
- 波次短劇情：1. 夜哨先看見草偶影子，張遼要求確認本體再集火。 → 2. 毒囊開始鼓脹，軍情標出真正的短射程威脅。 → 3. 棺盾領隊護送末段隊伍，守軍輪換目標避免浪費校射。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵、長戟兵、夏侯惇、典韋、許褚、張遼。
- 主要對手：替身偶屍、毒囊噴屍、腐釘弩屍。
- 末段領隊：棺盾小屍。
- 通關後解鎖：徐晃。
- 限制／反制：草偶數量與存活時間有限，標記不被草偶直接移除；每波間保留毒液消退的空窗。

**僵屍進攻**
張遼指揮弩兵集中火力。毒囊噴屍在棺盾後方接近，把腐液留在密集陣位，逼魏軍不能只靠站樁輸出。

- 重點：學會短射程持續範圍傷害與前排掩護配合。
- 波次短劇情：1. 屍軍發現張遼開始標記主攻路的第一個目標。 → 2. 棺盾掩護毒囊接近，噴吐前搖成為關鍵窗口。 → 3. 張遼領隊完成集火號令，末段改以輪換掩護突破。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍、煙罐小屍、鉤鎖屍卒、縫屍醫官、毒囊噴屍。
- 主要對手：大盾兵、強弩兵、張遼。
- 末段領隊：張遼。
- 通關後解鎖：替身偶屍。
- 限制／反制：腐液不附加暈眩或永久減防；噴屍需冒著接近風險，不能站在出場點就攻擊全圖。

### 08｜霜骨古道 — 內城決戰

**製圖／雪後薄暮：**古老石道、覆霜斷碑、枯松與散落盔甲，遠處出現高城牆輪廓。淡雪只是裝飾，不做冰面滑動或暴風特效。
建議檔名：`s2-08.webp`

**魏國守城**
厚盾與急縫護盾層層掩護屍群。徐晃拆開防護，張遼與弩兵跟上；斷旗咒屍在最後試探軍陣的支援。

- 重點：把破甲與集火接成完整攻擊鏈。
- 波次短劇情：1. 古道前段出現棺盾與急縫護盾的雙層防護。 → 2. 徐晃先拆盾，張遼標記暴露的關鍵目標。 → 3. 斷旗咒屍開始蓄咒，軍師尚未到場也能用普通火力處理。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵、長戟兵、夏侯惇、典韋、許褚、張遼、徐晃。
- 主要對手：棺盾小屍、縫屍醫官、破門撞屍。
- 末段領隊：斷旗咒屍。
- 通關後解鎖：郭嘉。
- 限制／反制：郭嘉通關後才取得；斷旗先以單一領隊登場，普通攻擊仍可擊倒，不把封策當唯一解。

**僵屍進攻**
徐晃開始快速拆盾，單靠棺盾已撐不住。替身偶屍分擔普通直射火力，煙霧與醫官接手，輪換掩護手段。

- 重點：學會不只依賴盾牌；使用誘餌、煙霧與治療交替推進。
- 波次短劇情：1. 屍軍確認徐晃會持續削弱同一面盾。 → 2. 草偶先吸收直射，煙霧與醫官接續補上掩護空窗。 → 3. 徐晃領隊踏上古道，末段必須靠多種掩護輪換而非單一棺盾。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍、煙罐小屍、鉤鎖屍卒、縫屍醫官、毒囊噴屍、替身偶屍。
- 主要對手：強弩兵、徐晃、典韋。
- 末段領隊：徐晃。
- 通關後解鎖：斷旗咒屍。
- 限制／反制：草偶不能吸走所有指定技能；魏軍不全路配置徐晃，仍保留普通小兵路線。

### 09｜魏武中軍 — 內城決戰

**製圖／戰前暗金：**靛藍中軍帳、排列整齊的魏旗、戰鼓與木製議事臺，後方是高城牆。深藍布帳配少量金色晨光，不放人物大頭或文字。
建議檔名：`s2-09.webp`

**魏國守城**
斷旗、草偶與醫官開始協同推進。郭嘉抓住施咒前搖，魏軍在技能空窗拆掉關鍵支援，迎接最後城門戰。

- 重點：判斷值得干擾的技能，不把控制平均分給每個小屍。
- 波次短劇情：1. 中軍報告斷旗、草偶與醫官分批入場，先辨認施咒者。 → 2. 郭嘉只干擾最急迫的蓄勢，普通敵仍由軍陣處理。 → 3. 破門撞屍在末段蓄勢，守軍把最後干擾留給真正的攻城窗口。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵、長戟兵、夏侯惇、典韋、許褚、張遼、徐晃、郭嘉。
- 主要對手：斷旗咒屍、替身偶屍、縫屍醫官、裂盾斧屍。
- 末段領隊：破門撞屍。
- 通關後解鎖：司馬懿。
- 限制／反制：同目標有干擾保護；先分批介紹組合，末段再混合，不堆成永久封控。

**僵屍進攻**
郭嘉與護衛守住中軍。斷旗咒屍暫時削弱友軍支援，屍軍用普通攻擊先逼出干擾，再抓空窗重新施咒。

- 重點：理解切斷外部增益，不等於刪掉武將自身天賦。
- 波次短劇情：1. 屍軍看見郭嘉正在監視第一個施法前搖。 → 2. 普通攻擊先逼出干擾，斷旗咒屍等待保護時間結束。 → 3. 司馬懿領隊進入中軍並開始蓄謀，末段要在層數成形前突破。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍、煙罐小屍、鉤鎖屍卒、縫屍醫官、毒囊噴屍、替身偶屍、斷旗咒屍。
- 主要對手：郭嘉、典韋、強弩兵、大盾兵。
- 末段領隊：司馬懿。
- 通關後解鎖：破門撞屍。
- 限制／反制：司馬懿最後才增援，先保留低謀略窗口；郭嘉可被普通輸出擊倒，不要求技能一定觸發。

### 10｜北境鐵壁 — 內城決戰

**製圖／破曉決戰：**巨大北境要塞主門、層疊城牆、對稱城樓與靛藍魏旗，冷白破曉穿過雲層，少量戰火。宏大但保持乾淨中央前景，不畫河道與船。
建議檔名：`s2-10.webp`

**魏國守城**
陷城屍督帶著破陣屍軍抵達主城門。司馬懿在護衛後方蓄謀，魏軍用卡位、破甲、集火與封策守住最後一線。

- 重點：有限混合波次後迎戰唯一的陷城屍督；清完敵軍與頭目立即勝利。
- 波次短劇情：1. 城樓逐波回報已排定的破盾、毒液與支援兵力，不猜測隨機兵種。 → 2. 司馬懿完成蓄謀前，魏軍依序卡位、破甲、集火並封住關鍵技能。 → 3. 混合波次清空後陷城屍督單獨進場，披甲、指揮與蓄勢重擊依階段明示。
- 首次挑戰可用：屯田兵、強弩兵、大盾兵、長戟兵、夏侯惇、典韋、許褚、張遼、徐晃、郭嘉、司馬懿。
- 主要對手：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍、煙罐小屍、鉤鎖屍卒、縫屍醫官、毒囊噴屍、替身偶屍、斷旗咒屍、破門撞屍。
- 最終頭目：陷城屍督。
- 通關後解鎖：曹操。
- 限制／反制：曹操是本關通關獎勵，首次挑戰不得要求他的軍旗。頭目有披甲、指揮、蓄勢重擊階段，但不無限召兵。

**僵屍進攻**
曹操在城門後整軍，魏國小兵也成為完整防線。破門撞屍利用前進距離累積衝勢，搭配全隊掩護與拆盾，攻破最後城門。

- 重點：整合破盾、誘餌、治療、斷旗與第一擊突破，而非只堆最貴角色。
- 波次短劇情：1. 屍軍逐波偵察魏軍旗臺，軍情標出每波真實守備人數與薄弱路。 → 2. 破門撞屍累積衝勢，盾、偶、煙與醫官輪流覆蓋其接近窗口。 → 3. 曹操最後整軍登場，小兵在軍令下強化；屍軍集中全部協同攻破一條合法路線。
- 首次挑戰可用：鼠牙群屍、腐釘弩屍、棺盾小屍、裂盾斧屍、煙罐小屍、鉤鎖屍卒、縫屍醫官、毒囊噴屍、替身偶屍、斷旗咒屍、破門撞屍。
- 主要對手：屯田兵、強弩兵、大盾兵、長戟兵、夏侯惇、典韋、許褚、張遼、徐晃、郭嘉、司馬懿。
- 最終頭目：曹操。
- 通關後解鎖：陷城屍督。
- 限制／反制：陷城屍督是本關通關獎勵，首次挑戰不能使用。精英分波分路上場，不同時塞滿所有武將；可破壞的薄弱路線必須存在。

## 戰鬥實裝的驗收門檻（尚未完成）

- 角色普通攻擊、固定天賦、機率技能與冷卻：逐個 deterministic hit/miss 測試，不讓支援、治療、標記與反傷無限循環。
- 領隊可沿用既有角色外觀另設關卡強度，不是新的可收集角色。最終頭目不得混入普通波次。
- 守城採有限敵軍、清楚的波次與末段頭目；清完即可勝利，不因剩餘倒數而拖延。資源、HP、出兵數量、時間與機率尚未定值，不宣稱已平衡。
- 難度依首次挑戰實際可用角色測試，不能使用當關的通關獎勵作弊驗收。
- 進攻每關保留可突破路線；不能讓煙霧、鉤鎖或封策任一角色成為唯一解。
- 客戶端與資料庫的角色資格、進度與首次通關獎勵皆通過後，才將設計預覽升級為可玩入口。
