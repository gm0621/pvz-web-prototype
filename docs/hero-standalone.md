# 英雄演義獨立版：現行開發規格

更新：2026-11-08。本文件描述本分支程式；發布狀態見 PROJECT_STATUS.md 頂部，不以文件完成代表正式站更新。

## 範圍與玩家流程

`/hero/` 為獨立三國演義遊戲；`/` 殭屍遊戲的入口、帳號、季度、商城與存檔保持獨立。純前端 ES modules，不載入原遊戲引擎或 Supabase，不搬移舊演義存檔。

首頁章回目錄 → 小說序幕／可略過的互動問答 → 人物對話 → 三路戰場 → 戰果與軍資 → 戰後營地 → 戰後對話 → 下一關。首頁沒有直接進營地的入口；敗戰仍能進營地整備後重試。戰前與戰後對話可回看上一句或略過。

四章二十二關：第一章六關（義軍初成、糧道遇襲、大興山迎敵、關羽初揚名、青州告急、三路破黃巾），第二章四關（廣宗拜師、長社火光、盧植蒙冤、義救董卓）。第三章六關（雨夜護鄉民、迷霧尋陣眼、青龍破風雨、黃旗再起、燕人震黃旗、風雨後的誓言），明示為遊戲原創支線。第四章六關（帝都風變、酸棗會盟、汴水撤軍、梁東突圍、陽人破敵、洛陽餘燼），以曹操與孫堅軍觀看 189～191 年討董歷史，見[第四章規格與史料](hero-history-chapter-four.md)。STAGES 合計 285 段戰前／戰後對話，不含小說序幕、歷史小札、問答及營地聊天；新增故事後以實際資料重算。

七張手繪場景供二十二關使用。歷史、演義與遊戲原創須清楚區分；原著參考為《三國演義》第一回。長社火攻不歸功劉備、劉備不劫救盧植、張角在本章敗後撤退。韓旌、焦魯、杜衡、石魁、雷烈為遊戲原創。

## 戰鬥與操作

三路、四卡；軍糧起始 220，每戰鬥秒 +12，上限 300。每路至多三名友軍。新出兵全部駐守，仍會攻擊射程內敵人；點單位再點地面或操作指令才移動。弓兵以單位 ID 個別調動，點弓兵卡是付費增援。

| 卡片 | 軍糧 | 射程（戰場比例） | 規則 |
| --- | --- | --- | --- |
| 弓兵 | 50 | .29 | 可重複出兵，冷卻 3 秒 |
| 劉備 | 90 | .08 | 每名武將在場唯一，退場整備 12 秒再付費召回 |
| 關羽 | 100 | .09 | 大刀近戰 |
| 張飛 | 110 | .11 | 長矛略長 |

可前進、後退、駐守、自動前進及換路；換路冷卻 2 秒，受路線容量限制。友軍可錯身，不因同路前鋒阻止後方近戰移動。前線 x=.84 駐守。

普通敵軍與支援將突破扣一格防線，三格耗盡敗戰；**關卡主將突破立即敗戰**。主將已出場、敵軍全部離場且沒有敗戰條件才勝利。張角被擊敗後的劇情撤退不算突破。

第 2～6 關逐步解鎖：劉備每 3 秒同路治療 13；張飛每 8 秒怒吼 16 傷害、震懾 1.1 秒及一般敵軍退後；關羽每 7 秒青龍斬 45；盾兵箭傷減半；三兄弟同時存活觸發一次桃園同心（全軍 +55、普攻 +20% 持續 5 秒）。招式資料以 skills.mjs 為準。

第三關起另有兩次跨路疾行兵突襲，不重複推進原波次。第八關張梁／張寶為支援將，分別施放風／雨技能；不搶主將單挑。第二章主將韓旌號令、焦魯火路、杜衡鉤鐮、張角符雷，依預警換路躲避。

## 第三章任務與大將交戰

戰前自動顯示前站到本關的路線、行軍旗與目的地，4.2 秒後收合，可直接略過。原創地點明示為示意位置，不冒充真實行軍史料。

第 11 關護送三隊鄉民（該路有友軍且敵兵未逼近才前進）；12 關依符號破三面真旗，猜錯不扣血；13 關先破兩旗解除張寶符障，再降至 60% 由關羽近身；14 關三波額外黃旗衝鋒；15 關避開張梁呼風可讓他失衡，60% 以下張飛近身；16 關護送三隊後讓三兄弟同時在場開路。任務未完成不結算，戰後營地增加鄉民對話。風雨／火勢／落石皆先預警並遵守戰鬥暫停。

主將開場護身架勢使傷害乘 0.6（前兩關 0.75），放過第一招後乘 0.8（前兩關正常）；大招後兩個戰鬥秒內不移動、不攻擊，受傷乘 1.25。第三關起主將半血只觸發一次狂攻：加快普攻並預告兩路技能。支援將不套護身／狂攻。單挑維持原觸發條件及劇情傷害，不受護身倍率影響。提示、金色護身光、橘色狂攻光與青色破綻光讀同一戰鬥狀態。

桌機選取單位後：方向鍵前／後／上／下，A 自動前進，S 駐守。文字欄位、選單、彈窗、暫停及單挑不接受移動快捷鍵；換路仍受容量與冷卻限制。

大將蓄力前 0.85 戰鬥秒顯示角色特寫、招式與危險路線，並播放一次鼓／鑼預警；兵器與法術音色不同，沿用音效開關及背景靜音。特寫不阻擋換路，退場後仍有剩餘蓄力預警；與戰鬥時間同步暫停，減少動態時保留靜態資訊。

## 單挑、動作與血條

九組一對一自動單挑由 duel-patterns.mjs 配置，不再共用同一套起手／反擊順序：

| 對戰 | 編排 |
| --- | --- |
| 張飛／鄧茂 | 搶攻、架矛、連刺 |
| 關羽／程遠志 | 接旋風、卸力、反斬 |
| 劉備／石魁 | 防錘、左右雙劍、破盾 |
| 關羽／韓旌 | 誘槍、撥槍、斷旗 |
| 張飛／焦魯 | 長矛逼退、架雙刀、散焰 |
| 劉備／杜衡 | 鎖鉤、反挑、側步雙斬 |
| 劉備／張角 | 避雷、破符、開路撤敵 |
| 關羽／張寶（13） | 避雨符、回刀斷符、收雨撤敵 |
| 張飛／張梁（15） | 架環刀、回身連刺、震軍挑旗 |

第六關另有關羽、張飛對雷烈二打一：兩將須存活在場，關羽同路近身觸發。雷烈三格揮斧依反擊時間切換蓄力／劈下／收招；兩將各受反擊一次。

各組有不同事件時間、傷害分配、招式文字及武器位移。仍為自動演出，不新增選招或隨機勝負。開場 3.2 秒、交手 19 秒均為單挑時鐘；播放倍率 .805，不暫停約 27.6 秒現實時間。略過只跳開場，不跳交手。

雙方血條與 HP 數字讀取戰局實際 hp/maxHp，進入單挑不補滿敵將。敵方每次反擊出手後 .6 秒命中，我將扣最大生命 3%，每場兩次，共 6%，至少保留 1 HP；受傷延續回戰場。各將依專屬終結技時間清零（約 15～16 秒），張角及第三章二張以破陣撤退呈現；餘兵仍需處理。

暫停／回首頁／頁面隱藏凍結單挑，單挑期間戰場時間、軍糧、波次、冷卻與地面傷害不推進。血條不使用獨立時間動畫。減少動態偏好保留文字、血條與狀態，停用人物位移。

三將普攻 .58 秒、.24 秒命中；敵兵揮擊 .66 秒、.24 秒命中。張飛繼續重用第四格避開貼邊第五格。動作與特效使用戰鬥時鐘；素材詳見 hero/assets/attacks/README.md。

## 營地、本機保存與音訊

- 首次通關每關 80 軍資，重玩及敗戰 +0，軍資上限 99,999；結算顯示實際增加額。
- 藥包 25（全軍 +60 HP）、糧袋 20（+80 糧，上限 300），單種最多 9。滿血／滿糧不耗用；暫停、出場劇情、單挑、結算不能使用。
- 三將兵器各至多強化三次，價格 60／120／180；劉備每級普攻 +3，關羽／張飛 +4。購買後自動裝備，新戰局取兵器快照。
- `heroLegendProgress_v1`：`version:1`、`completed:0..16`、`coins`、`rewarded`、`inventory:{herb,grain}`、`weapons:{liubei,guanyu,zhangfei}`。缺 coins 的舊存檔按已通關數 ×80 遷移；正規化後 rewarded 由完成關數重建。
- 不按帳號區分、不跨裝置。保存失敗保留當頁資料並顯示尚未保存；成功保存後清除警告。回首頁保留當頁暫停戰局，重整不還原戰鬥中的單位、冷卻、單挑。
- 七種場景配樂：首頁、故事、整備、戰鬥、單挑、營地、勝利。戰鬥為〈晴野行軍〉；錄製音訊失敗可退回合成曲。角色人聲已移除，保留兵器與風雨雷等音效。

## 檔案與驗證

story.mjs 組合兩章；chapter-two.mjs 與 chapter-bosses.mjs 提供第二章資料；engine.mjs 管規則；duel-patterns.mjs 管單挑編排；duel-view.mjs／duel-entrance.mjs 管單挑呈現；app.mjs 管畫面與保存；campaign.mjs／camp-view.mjs 管營地；audio.mjs 管配樂。

執行 `npm run test:hero:engine` 及相關 `tests/hero-*.spec.js`。引擎十關各三種子通關是指定策略樣本；受控單挑／結算測試不是自然通關或真人平衡驗證。實際測試結果與尚未完成項目見交接頂部。
