# 英雄演義獨立版：桃園同心

本文件取代舊版共用選單規劃。遊戲位於 `/hero/`，原遊戲位於 `/`，以後的遊戲入口直接連結這兩個網址；本次不製作入口平台。

## 玩家流程

獨立首頁先呈現桃園場景，「開始故事／繼續故事」→ 場景中的人物對話（可回看上一句或跳過）→ 三路戰場 → 戰果 → 戰後對話 → 下一關。六關共 77 段對話，沒有旁白說話者。每關有獨立場景圖，戰場也隨關卡換景；桌機三人同框，手機以說話者與對話對象雙人同框，說話者亮起。戰鬥左上可回主選單，當頁保留暫停戰局，重整後從尚未完成關卡重玩。

選一張兵卡，再點上、中、下任一路出兵。軍糧自動補給（每秒 12，上限 300），部隊自動前進、攻擊；每路最多三名友軍。劉備／關羽／張飛各只能在場一位，退場後整備 12 秒，再支付軍糧召回；弓兵可重複出兵，冷卻 3 秒。敵軍突破三次失敗，清空本關敵軍與敵將獲勝。沒有裝備、升級、商城、帳號、手動收糧或難度選擇。

| 卡片 | 軍糧 | 工作 |
| --- | --- | --- |
| 弓兵 | 50 | 後排遠程支援 |
| 劉備 | 90 | 近戰支援；第 2 關起每三秒回復同路友軍 13 生命 |
| 關羽 | 100 | 高傷害近戰；第 4 關起自動青龍斬 |
| 張飛 | 110 | 高生命前鋒；第 3 關起自動怒吼震退及震懾 |

## 動作與邊界

保留立繪，透過上身／雙腳分層呈現待機、踏步、前傾揮擊、拉弓及受擊；刀光、飛箭、治療、怒吼與青龍斬為獨立特效。場上節點持續保留，避免每幀重建造成動畫重播。暫停／單挑期間也凍結動畫與特效，尊重系統減少動態偏好。

三路有實線邊界、土色行軍帶、方向箭頭與出兵區。部隊到達前線 x=.84 就駐守，不再走出畫面消失；敗退有淡出倒退，敵軍突破有衝線退場與防線受損提示。

## 逐關加入玩法

每關只教一個新重點，招式自動觸發，不增加手動技能按鈕。重玩早期關卡仍使用該關的簡單規則。

1. 三路布陣、普通近戰與弓兵，認識同名武將唯一及退場冷卻。
2. 劉備仁德：每三秒回復同路友軍 13 生命。
3. 張飛燕人怒吼：每八秒對身前同路敵軍造成 16 傷害、震懾 1.1 秒；一般敵軍退後 .065，頭目不被推動。
4. 關羽青龍斬：每七秒對身前 .23 範圍同路所有敵軍造成 45 傷害。
5. 黃巾盾兵：箭傷減半，近戰及招式不減傷；配合前鋒與弓兵突破。盾兵從本關才開始出現。
6. 桃園同心：三兄弟同時存活在場，每場第一次集結回復全軍 55 生命，普通攻擊提升 20% 持續五秒。

冷卻到時且有合適敵人，才自動施放攻擊招式，沒有敵人時不空放。卡牌顯示本關能力、出戰中或整備秒數；本關新機制顯示於標籤與提示，出招有獨立名稱及特效。

## 六關

| 關卡 | 劇情與任務 | 特別呈現 |
| --- | --- | --- |
| 義軍初成 | 桃園立誓、訓練鄉勇 | 結義改編；練兵為補充情節 |
| 糧道遇襲 | 清開被散兵攔住的糧道 | 遊戲改編，沒有額外糧車操作 |
| 大興山迎敵 | 張飛迎戰鄧茂 | 兩將接近自動短單挑 |
| 關羽初揚名 | 關羽迎戰程遠志 | 兩將接近自動短單挑 |
| 青州告急 | 援軍突破城外山道 | 三路照應、前鋒掩護弓兵 |
| 三路破黃巾 | 劉備引敵，關張呼應 | 章末三路交鋒；勝利接盧植線索 |

劇情是《三國演義》的遊戲改編，不宣稱史實。所有關卡共用簡單交鋒規則，沒有另開攻城、護送、伏擊操作系統。第三、四關指定武將遇敵將，播放約 2.2 秒單挑，同時凍結戰鬥時間、出兵與軍糧。單挑後敵將減少最大生命 30%，我將減少 5%，皆至少留 1 點生命，繼續原戰鬥；不需要選招。暫停也凍結單挑。

## 檔案與進度

`hero/engine.mjs` 為純戰鬥狀態與規則；`story.mjs` 為角色與六關台詞／參數；`app.mjs` 負責畫面與本機保存，`game.css` 為獨立響應式畫面。只載入自身模組，不載入 Supabase、商城或舊引擎。弓兵、黃巾代用圖和音樂可引用既有靜態素材。

新進度 `heroLegendProgress_v1` 僅保存 `{version:1, completed:0..6}`。不跨裝置，不按登入身份分開，不讀寫殭屍 profile 與舊版演義進度。儲存失敗會提示只能在當頁保留進度。

## 素材

人物統一採用關羽的 Q 版手繪風格。劉備與張飛由內建圖片生成工具重新設計，關羽保留原圖，獨立存放於 `hero/assets/`。新增六張原創場景：桃園、運糧小徑、大興山、黃巾營地、青州城外與伏兵山口。生成參考與提示見 [素材說明](../hero/assets/README.md)。原遊戲人物圖片不變。

## 驗證

`npm run test:hero:engine` 驗證費用、武將唯一與召回、逐關技能、前線駐守、視覺事件、路線容量、暫停、單挑與勝負，六關各用三個種子合法出兵模擬。這是指定策略的樣本，不代表真人勝率。`tests/hero-standalone.spec.js` 在桌機／手機驗證入口、部署、暫停、獨立進度及第一關經由實際 UI 出兵通關。
