# 第十八章「五丈原秋風」

接續第 100 關武都陰平。故事依 230、231、234 年的史事推進，三路兵卡與養成沿用蜀漢軍。關卡的對手頭像代表該段史事的魏軍指揮者，戰鬥以小隊接應、補給和撤離為主。

| 關卡 | 史實與行軍圖 | 過關任務 |
| --- | --- | --- |
| 101 雨阻漢中 | 230 年，江州 → 南鄭。李嚴調往漢中，曹真伐蜀時連日大雨、棧道斷絕，奉命撤軍。 | 各路接應累計 24 秒，清退餘兵。 |
| 102 祁山運糧 | 231 年，沔陽 → 祁山。蜀軍用木牛運糧，後方遇久雨，糧運不繼而退兵。 | 送出三批營中存糧，發車時每路都要安全。 |
| 103 木門收兵 | 231 年，祁山 → 木門一帶。張郃追擊蜀軍，在木門中箭身亡。 | 接應後下令撤離，至少一隊存活，全部撤回左側。 |
| 104 斜谷再出 | 234 年春，沔陽 → 斜谷 → 五丈原。諸葛亮用流馬運糧，與司馬懿相持。 | 接應三隊使者，清退餘兵。 |
| 105 渭濱屯田 | 234 年，五丈原 → 渭水南岸。諸葛亮分兵屯田，準備久駐。 | 整備田畦、水渠和糧棚，清退餘兵。 |
| 106 五丈原歸途 | 234 年秋，五丈原 → 斜谷 → 沔陽。諸葛亮病逝，楊儀帶各營撤回漢中。 | 接應後下令撤離，保住至少一隊並讓所有存活友軍回到左側。 |

地圖以歷史區域示意，木門道的確切位置有不同說法。第 101 關顯示李嚴的接應方向，曹真在另一戰線。第 106 關以斜谷和沔陽示意退回漢中的方向，司馬懿不跟隨蜀軍頭像移動。過關任務與營地對話屬遊戲改編。祁山局部送糧成功後仍保留缺糧撤兵，末關撤離後仍交代諸葛亮病逝。史料連結也收錄於各關的「歷史小檔案」。
