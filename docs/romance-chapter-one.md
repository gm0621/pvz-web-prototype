# 英雄演義：第一章・桃園結義

主畫面分為「大戰殭屍」與「英雄演義」兩個入口。原本的守城、進攻、新手開局與季度選擇收在「大戰殭屍」內；下方圖鑑、玩家資料與商城共用，返回首頁會回到雙模式入口。演義模式與屍潮第一、二季共用部署、軍糧、冷卻、戰鬥、波次、難度與劇情對話。內部以 season 3 識別，沒有複製整套遊戲。

## 章節流程

桃園結義（序幕） → 義軍初成 → 糧道遇襲 → 大興山迎敵 → 關羽初揚名 → 青州告急 → 三路破黃巾 → 英雄初立功（結章）。

| 關卡 | 戰鬥形式 | 實際勝利條件 |
| --- | --- | --- |
| 1-1 義軍初成 | 演武練兵 | 清除演練部隊與演武教頭 |
| 1-2 糧道遇襲 | 護送 | 中央路糧車存活並抵達終點，擊敗全數敵軍 |
| 1-3 大興山迎敵 | 雙方進攻、張飛對鄧茂 | 己營仍存在時將敵營生命降至零 |
| 1-4 關羽初揚名 | 敵將決戰、關羽對程遠志 | 清除敵軍與程遠志 |
| 1-5 青州告急 | 突圍救援、雙方進攻 | 攻破青州城外阻截敵營 |

主要情節依《三國演義》第一回順序改編。練兵、糧道遭襲與戰場目標是遊戲補充；不將改編戰鬥宣稱為歷史。台詞為重新撰寫，序幕、各關戰前／勝利／失敗、結章收錄於 `js/romance-data.js`。下一章「黃巾烽火」只有預告，未開放。

## 雙方進攻

- 仍採五路、九欄棋盤；己方出兵區縮至左側三欄。
- 義軍刀兵會自行前進接戰；此類關卡中的劉關張也會向敵陣推進。軍糧官、盾將、弓兵保留原有部署行為。
- 雙方營地生命常駐顯示：義軍 1000、黃巾 800。己方行軍單位抵達敵營後，依攻擊節奏持續攻營；每名敵軍穿過己方底線扣 200 己營生命。
- 雙方進攻不設救場推車；護糧、演武與決戰保留現有防線規則。
- 不以清空敵軍代替攻營勝利；營地數值跟隨戰局保存，暫停時不推進。

## 武將單挑

1-3 張飛與鄧茂、1-4 關羽與程遠志，在同一路相距 1.6 格內時觸發。敵將在戰鬥第 25 秒進場；原有普通部隊繼續按波次出兵。每場同一敵將只叫陣一次。

叫陣時暫停全軍，玩家選「接受單挑」或「繼續混戰」。單挑採三回合：強攻克佯攻、佯攻克格擋、格擋克強攻，相同則平手；敵將每回合隨機選招。這是首版的選招玩法，沒有即時反應或操作連段。

- 勝：敵將扣最大生命 35%，己將振奮 5 秒。
- 負：己將扣最大生命 25%，敵將振奮 5 秒。
- 平：雙方各扣最大生命 10%。
- 振奮透過增加攻擊準備進度加快出手；不直接更改永久角色數值。
- 單挑不直接擊倒武將，最低保留 1 生命。返回戰場才套用一次結果；取消尚未完成的單挑則回到混戰，無額外收益。
- 單挑過程重新整理，可恢復當前回合。暫停、閱覽與單挑不推進戰鬥時間。

## 第一版範圍與保存

演義通關與閱讀紀錄按瀏覽器及目前帳號／訪客分開保存。暫存戰局沿用既有單一未完成戰局機制；開始另一場會取代原暫存。原兩季進度、帳號金幣與經驗不變。

尚未新增演義雲端進度與獎勵 RPC，本章不發金幣或角色 XP，也不以演義戰果呼叫原季度對戰 RPC。通關獎勵為解鎖故事；六關完成後顯示「桃園同心」章節紀念，不是可裝備道具。畫面已說明本機保存與獎勵範圍。

黃巾兵將第一版使用現有的人類兵種圖與黃巾色調；尚未製作鄧茂、程遠志專屬立繪。劉關張沿用現有技能與角色養成效果。
