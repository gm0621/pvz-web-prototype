# 第二十六章 東宮風雲

第 149～154 關從 291 年洛陽再變後接到 301 年趙王司馬倫篡位。司馬遹被廢、移送許昌和後來遇害分開交代。結尾停在惠帝遷往金墉城，八王之亂仍在發展。

| 關卡 | 行軍圖或交接地 | 任務與史實 |
| --- | --- | --- |
| 149 賈后掌權 | 洛陽宮城議事地，張華處理朝政 | 整備奏章、官籍和驛書。賈皇后掌權，司馬衷仍在位。 |
| 150 東宮廢立 | 洛陽東宮，賈南風主張廢立 | 接應三隊使者。張華、裴頠替司馬遹辯護，太子仍被廢。 |
| 151 許昌幽居 | 洛陽 → 許昌 | 送三批隨行補給。司馬遹被送往許昌，後來在當地遇害。 |
| 152 賈后被廢 | 洛陽宮城 → 金墉城 | 各路累積守備 24 秒並清退亂兵。賈后被廢，張華與裴頠遇害，司馬倫和孫秀掌權。 |
| 153 淮南王起兵 | 洛陽街巷 → 洛陽城門，遊戲撤離路線 | 讓存活友軍撤回左側。司馬允起兵反對司馬倫，最後敗亡。 |
| 154 趙王篡位 | 洛陽宮城 → 金墉城，標示司馬倫篡位 | 接應三隊使者。司馬倫奪取皇位，司馬衷受監視居於金墉城。 |

第 152、153 關有敵波，分別以守備和撤離呈現朝廷動亂。第 152、154 關皆標示金墉城，人物、年份、任務各自對應當時的事件。六關沿用西晉篇的選將與兵器存檔。兵卡、任務、部分路線與營地對話為改編。
