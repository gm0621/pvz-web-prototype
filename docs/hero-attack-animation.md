## 使用者要解決的問題

舊版近戰主要是同一張人物立繪平移／旋轉，手與武器沒有真正改變姿勢。新版將劉備、關羽、張飛的戰場攻擊改為重新繪製的連續姿勢，讓蓄力、出手、命中、收招都看得出來。

- 劉備：雙劍拉回、交叉斬擊、收劍。
- 關羽：雙手舉刀、劈落、順勢收刀。
- 張飛：收槍、壓低身體、踏前突刺、收槍。

首頁與劇情人物繼續使用原圖；弓兵、敵兵、角色能力、逐關學習、武將唯一與 12 秒召回規則沿用。沒有增加操作按鈕，也沒有改原殭屍遊戲的程式。

## 時間與命中契約

一段攻擊約 0.58 秒，`SWING.frameTime` 為 0.08 秒，依戰鬥時間計算索引。前六格約為準備、蓄力、出手、命中、順勢、收招；末格停留至動作結束。張飛延伸停頓重用第 4 格，避開第 5 格槍尖貼齊分格邊界。

近戰開始時記錄 `swingStartedAt`、目標 ID 與 `pendingStrike.impactAt`，約 0.24 秒進入第 4 格才扣血、顯示刀光與受擊。青龍斬也改成等待命中格；若同一時刻已有普通攻擊，配合該次命中時點，避免手仍在蓄力就先傷害。

命中前武將退場，排程隨該武將移除；目標已退場或不再符合命中條件，不追加傷害。收招期間不繼續滑行。既有攻擊間隔仍是兩次起手之間的冷卻，沒有加快連打。

姿勢來自 `battle.time`，而非獨立的現實時間 CSS 動畫，因此暫停、回主選單及單挑會凍結在原影格。不要改成會在背景繼續播放的 GIF 或獨立計時器。武將圖必須保留透明 alpha，不能把生成預覽底色當成遊戲背景。

## 如何重現與驗證

先讀根目錄 `AGENTS.md`，再依 `docs/DEVELOPMENT.md` 安裝環境。使用標準設定，不要提交個人瀏覽器路徑或本機測試設定。

```sh
npm ci
npx playwright install chromium
npm run test:hero:engine
npm test -- tests/hero-standalone.spec.js --workers=1
```

本次實際結果：19 項 Node 引擎測試與 20 項桌機／手機 Playwright 檢查通過。三位武將都在真實瀏覽器渲染出不同姿勢，並檢查圖片透明區與攻擊圖的不同影格；第一關經正常 UI 出兵通關，六關各三個種子仍能合法出兵通關。這些是指定策略樣本，不代表真人勝率或完整平衡評估。

本次使用 macOS、本機 Chrome、Node 24、Playwright 1.65 的未提交本機設定；儲存庫鎖檔為 Playwright 1.62.1，其他電腦用 `npm ci` 重現自己的環境。

人工檢查：進入 `/hero/`，出任一武將到中路，等交戰後觀察武器與手臂姿勢確實變換；確認刀刃落下才有受擊。試暫停、返回主選單續戰；第 4 關檢查青龍斬的刀光與動作同步。發布後需再檢查正式站，不以 PR 合併代替。

## 下一步與限制

目前為手繪逐格 2D 動作，尚非骨骼動畫或 3D。待機／行軍仍使用準備姿勢配合踏步位移；本次重點是近戰出招。後續若增加行走、受擊或專屬技能圖，沿用同一姿勢尺寸與腳底基準，避免角色換圖時忽大忽小。

若要加密影格或改出手速度，請一起調整 `SWING`、素材排列、命中時點與測試；不要只改視覺速度，讓傷害和刀刃再度錯開。正式網址：[英雄演義](https://gm0621.github.io/pvz-web-prototype/hero/)。
