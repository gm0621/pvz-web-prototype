# 八王之亂外傳：洛陽風雲

第 161～166 關是獨立可選番外。第 160 關「齊王輔政」尾聲回主選單。完成該關後，選擇《八王之亂外傳：洛陽風雲》開始新故事。已完成第 160 關的存檔可直接進入。第 142 關仍是主篇結局。

| 關卡 | 行軍圖 | 任務與史實 |
| --- | --- | --- |
| 161 齊府勸諫 | 齊王府 | 接應三隊使者。鄭方到洛陽上書，提醒齊王留意百姓困難。 |
| 162 河間傳檄 | 長安 → 洛陽 | 信封代表傳檄使者。李含勸司馬顒討伐齊王，檄文點名司馬乂。 |
| 163 宮城三日 | 洛陽街巷 → 洛陽宮城 | 宮門守備累積 24 秒並清退敵波。司馬乂奉惠帝抵抗齊府，三日後齊王戰敗遇害。 |
| 164 長沙輔政 | 洛陽宮城 | 整備糧倉、城防和公文。司馬乂掌理朝政，惠帝仍在位。 |
| 165 兩王攻洛 | 鄴城 → 洛陽及長安 → 洛陽 | 從守軍視角攔住逐波來敵。突破後會扣城門耐久，戰中可修補兩次。陸機、張方分屬成都王與河間王兩路。 |
| 166 洛陽圍城 | 洛陽宮城 → 金墉城 | 守住城門 40 秒，城門受損可修補兩次。倒數結束後讓所有存活友軍撤回，至少保住一隊。尾聲交代司馬越等人拘押司馬乂、送到金墉城，張方部下帶走司馬乂後，他最終遇害。 |

關卡時間軸沿用太安元年（302）、太安二年（303）及永興元年（304）的年號換算。太安元年末採史書農曆年次。行軍圖為分辨地點與隊伍的示意。接應、守備計時、城內撤離及營地對話均為遊戲改編。第 166 關的撤離成功代表撤離隊平安返回，司馬乂的史實結局由戰後劇情交代。
