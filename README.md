# 三國萌將守城：屍潮來襲｜網頁版遊戲原型

一個純前端 HTML/JavaScript 小遊戲原型：開頭可選三國守方或僵屍方，接著進入獨立選關頁；第一階段已重新拆成十關，可直接跳任一關測試。主選單使用正式 LOGO 圖 `assets/brand/sanguo-zombie-logo.webp`，favicon / Apple touch icon 使用同張圖製作的 icon 資產。

## 玩法

- 流程：先選陣營 → 進入選關頁 → 直接開始第一階段第一～第十關。
- 選關頁：第一階段總共十關。第一、二關共用原第一關白天圖但名稱不同；第三、四關也是白天新關；第五、六關由原第二關夜戰拆成兩關；第七、八關由原第三關攻城拆成兩關；第九、十關由原第四關決戰拆成兩關。每張關卡卡片已改成較有劇情的戰場說明，並新增獨立「出場人物」區塊，列出該關重點守方與僵屍角色。
- 第一關｜草坪試煉：入門 1，白天基礎教學，只開伏兵、軍糧官、盾將、蜀軍弓兵，以及一般/鐵甲僵屍。
- 第二關｜軍糧小徑：入門 2，仍使用白天草坪圖，加入關羽火焰將、獸之巨人與擲石僵屍。
- 第三關｜白日突圍：普通 1，白天新關，解鎖寒冰趙雲與跳躍僵屍。
- 第四關｜前線演武：普通 2，白天新關，解鎖火神龐統、穿刺馬超與僵屍王將軍。
- 第五關｜鐵甲夜襲：進階 1，由原第二關拆出，進入夜戰並解鎖百箭黃忠、小丑僵屍。
- 第六關｜夜半奔襲：進階 2，由原第二關拆出，解鎖鬥神張飛與炸彈小丑。
- 第七關｜火石攻城：將軍 1，由原第三關拆出，解鎖軍神孔明與屍旗巨魁。
- 第八關｜烈焰破陣：將軍 2，由原第三關拆出，投石車僵屍正式登場。
- 第九關｜群魔決戰：決戰 1，由原第四關拆出，仁德劉備加入，雙方全角色開放。
- 第十關｜屍潮終局：決戰 2，由原第四關拆出，是第一階段最終壓力關。
- 三國守方：部署蜀軍弓兵、軍糧官、盾將、伏兵、關羽火焰將防守戰線；每一路有一台最後防線推車，僵屍碰到時會衝整排並清掉該路僵屍。
- 僵屍方：派出僵屍、吃掉守方角色直接獲得腦資源；電腦三國守方也有推車，每一路第一次被突破會先清掉整路僵屍；如果腦資源不足且場上無僵屍可繼續推進就輸。
- 資源不會掉在畫面上，避免誤以為要點擊收集；軍糧/腦只會在 HUD 數字更新。
- 叫出守方角色或僵屍都有冷卻時間，卡片底部會顯示冷卻進度。遊戲中角色卡已改成小卡橫向排列，讓棋盤更大、點選距離更短；可先點卡片再點格子，也可以把卡片拖曳到格子上直接叫出角色。暫停時卡片會放大並顯示角色說明，方便玩家慢慢看能力。
- 關卡的電腦出兵、防線與補能量節奏會隨機變化，不會每次完全相同；新版電腦會依照場上哪一路壓力最大來選擇派兵/補防，不再完全亂丟。
- 電腦強單位有延後出場門檻：守城戰不會一開始就派獸之巨人、擲石僵屍、跳躍僵屍、僵屍王將軍或後續將軍級攻城單位；進攻戰的電腦守方也會先鋪軍糧官、盾將、弓兵等基本防線，再逐步使用關羽、趙雲、張飛、孔明、劉備等強武將。守城戰的電腦僵屍方初始腦力已提高，但出兵節奏改成前 15 秒較慢、中段恢復、後段才加快；出兵路線會隨機從前三個破口候選挑選，優先找守軍較少、推車已用掉、或有機會攻破的薄弱路線，不再一直壓同一線。
- 已加入三國守方 PNG 素材與新版僵屍方 PNG 素材，放在 `assets/characters/`；守方為蜀軍弓兵、軍糧官、盾將、伏兵、關羽火焰將；僵屍方為一般僵屍、鐵甲僵屍、獸之巨人、僵屍王將軍、擲石僵屍、跳躍僵屍、小丑僵屍、炸彈小丑、屍旗巨魁、投石車僵屍。
- 小丑僵屍是將軍級混亂術師：紫紅破袍、骷髏金飾與邪笑權杖象徵屍潮中的恐懼指揮官；能力「亂陣狂笑」會震懾同一路守方，造成傷害並讓守方短暫混亂停手，適合在防線密集時撕開破口。
- 炸彈小丑是將軍級爆破狂徒：雙角紫紅小丑帽、骷髏炸彈與燃燒導火線代表他把戰場當成最後舞台；能力「終幕爆彈」會在被打敗時自爆，對自身周圍九宮格內守方造成重創，逼三國守方分散站位。
- 屍旗巨魁是將軍級攻城巨屍：背負「屍」字戰旗，肩上屍兵敲鼓催戰，手持帶刺攻城巨槌碾碎防線；能力「破城屍槌」會重擊前方守方，並震傷目標周圍九宮格內守方、短暫打斷行動，是屍潮最後壓線的主將。
- 投石車僵屍是將軍級攻城兵器：木製戰車綁滿鐵刺、骷髏旗與紅色戰布，車上僵屍操縱燃燒巨石轟向城牆；能力「烈焰轟石」會遠距離鎖定同一路防線最密集處，砸下火焰巨石並對目標周圍九宮格造成濺射傷害。

## 僵屍方角色

- 一般僵屍：便宜基本兵。
- 鐵甲僵屍：中階防禦。
- 獸之巨人：高血量重壓。
- 擲石僵屍：遠程投石。
- 跳躍僵屍：第二關新增，先快跑並跳過一名守方角色。
- 僵屍王將軍：強力菁英。

- 投石車僵屍：將軍級攻城兵器，使用「烈焰轟石」遠距離轟炸同一路最密集防線，對目標周圍九宮格造成火焰濺射傷害。

## 未來商城 / 將軍能力

- 未來商城可使用目前已存在的金幣與經驗值，兌換或升級將軍能力。
- 劉備預留四個能力素材：仁德治世、昭烈之志、以德服人、匡扶漢室。
- 劉備四張戰鬥動作圖也已獨立保存，後續可在攻擊、治療、防守或技能施放時切換圖片。

詳細素材與能力 manifest：`assets/characters/future-generals/future-generals.json`。

直接打開 `index.html` 即可遊玩。
