# 萌將守城戰｜網頁版遊戲原型

一個純前端 HTML/JavaScript 小遊戲原型：開頭可選三國守方或僵屍方，接著進入獨立選關頁；第一階段已重新拆成十關，可直接跳任一關測試。

## 玩法

- 流程：先選陣營 → 進入選關頁 → 直接開始第一階段第一～第十關。
- 選關頁：第一階段總共十關。第一、二關共用原第一關白天圖但名稱不同；第三、四關也是白天新關；第五、六關由原第二關夜戰拆成兩關；第七、八關由原第三關攻城拆成兩關；第九、十關由原第四關決戰拆成兩關。
- 第一關｜草坪試煉：入門 1，白天基礎教學，只開伏兵、軍糧官、盾將、蜀軍弓兵，以及一般/鐵甲僵屍。
- 第二關｜軍糧小徑：入門 2，仍使用白天草坪圖，加入關羽火焰將、獸之巨人與擲石僵屍。
- 第三關｜白日突圍：普通 1，白天新關，解鎖寒冰趙雲與跳躍僵屍。
- 第四關｜前線演武：普通 2，白天新關，解鎖火神龐統、穿刺馬超與僵屍王將軍。
- 第五關｜鐵甲夜襲：進階 1，由原第二關拆出，進入夜戰並解鎖百箭黃忠、小丑僵屍。
- 第六關｜夜半奔襲：進階 2，由原第二關拆出，解鎖鬥神張飛與炸彈小丑。
- 第七關｜火石攻城：將軍 1，由原第三關拆出，解鎖軍神孔明與屍旗巨魁。
- 第八關｜烈焰破陣：將軍 2，由原第三關拆出，投石車僵屍正式登場。
- 第九關｜群魔決戰：決戰 1，由原第四關拆出，仁德劉備加入，雙方全角色開放。
- 第十關｜屍潮終局：決戰 2，由原第四關拆出，是第一階段最終壓力關。
- 三國守方：部署蜀軍弓兵、軍糧官、盾將、伏兵、關羽火焰將防守戰線；每一路有一台最後防線推車，僵屍碰到時會衝整排並清掉該路僵屍。
- 僵屍方：派出僵屍、吃掉守方角色直接獲得腦資源；電腦三國守方也有推車，每一路第一次被突破會先清掉整路僵屍；如果腦資源不足且場上無僵屍可繼續推進就輸。
- 資源不會掉在畫面上，避免誤以為要點擊收集；軍糧/腦只會在 HUD 數字更新。
- 叫出守方角色或僵屍都有冷卻時間，卡片底部會顯示冷卻進度。
- 關卡的電腦出兵、防線與補能量節奏會隨機變化，不會每次完全相同；新版電腦會依照場上哪一路壓力最大來選擇派兵/補防，不再完全亂丟。
- 電腦強單位有延後出場門檻：守城戰不會一開始就派獸之巨人、擲石僵屍、跳躍僵屍、僵屍王將軍或後續將軍級攻城單位；進攻戰的電腦守方也會先鋪軍糧官、盾將、弓兵等基本防線，再逐步使用關羽、趙雲、張飛、孔明、劉備等強武將。
- 已加入三國守方 PNG 素材與新版僵屍方 PNG 素材，放在 `assets/characters/`；守方為蜀軍弓兵、軍糧官、盾將、伏兵、關羽火焰將；僵屍方為一般僵屍、鐵甲僵屍、獸之巨人、僵屍王將軍、擲石僵屍、跳躍僵屍、小丑僵屍、炸彈小丑、屍旗巨魁、投石車僵屍。
- 小丑僵屍是將軍級混亂術師：紫紅破袍、骷髏金飾與邪笑權杖象徵屍潮中的恐懼指揮官；能力「亂陣狂笑」會震懾同一路守方，造成傷害並讓守方短暫混亂停手，適合在防線密集時撕開破口。
- 炸彈小丑是將軍級爆破狂徒：雙角紫紅小丑帽、骷髏炸彈與燃燒導火線代表他把戰場當成最後舞台；能力「終幕爆彈」會在被打敗時自爆，對自身周圍九宮格內守方造成重創，逼三國守方分散站位。
- 屍旗巨魁是將軍級攻城巨屍：背負「屍」字戰旗，肩上屍兵敲鼓催戰，手持帶刺攻城巨槌碾碎防線；能力「破城屍槌」會重擊前方守方，並震傷目標周圍九宮格內守方、短暫打斷行動，是屍潮最後壓線的主將。
- 投石車僵屍是將軍級攻城兵器：木製戰車綁滿鐵刺、骷髏旗與紅色戰布，車上僵屍操縱燃燒巨石轟向城牆；能力「烈焰轟石」會遠距離鎖定同一路防線最密集處，砸下火焰巨石並對目標周圍九宮格造成濺射傷害。
- 首頁新增「角色介紹 / 能力圖鑑」頁，可切換查看三國守方與僵屍方，每個角色都有圖片、消耗與能力說明；角色卡片與圖鑑已改成由弱到強排序，方便從基礎兵種一路看到將軍級角色。
- 角色圖鑑的「三國守方 / 僵屍方」切換按鈕改成同尺寸，選取時會換成黃色高亮。
- 角色介紹頁文案改成較像角色設定的介紹詞；軍糧官名稱已移除「小軍師」避免過長。劉備圖鑑圖已換成圖2；關羽角色介紹與遊戲中都使用原圖；攻擊時不再換圖，改用原圖短暫向前翻轉/揮刀動畫。
- 主選單改成精簡三國大廳：使用 `assets/backgrounds/main-menu-battle-bg.webp` 戰場背景，只保留三個目前可用入口（守城戰、進攻戰、能力圖鑑）；多餘功能圖示已移除，右上角保留音樂/音效獨立開關。
- 最外層主選單遊戲名稱改為「三國屍潮：萌將守城」。
- 關卡選擇頁改成三國戰場卡片風格，第一階段顯示十張關卡卡片；第一～四關為白天，五～六關使用原第二關夜戰圖，七～八關使用第三關火石攻城圖，九～十關使用第四關群魔決戰圖。進入遊戲後棋盤背景維持原本草地/夜晚格線，不使用關卡選擇圖。
- 角色解鎖節奏已改成依十關慢慢開放：第一關基礎防線；第二關關羽/獸巨/擲石；第三關趙雲/跳躍；第四關龐統/馬超/僵屍王；第五關黃忠/小丑；第六關張飛/炸彈小丑；第七關孔明/屍旗巨魁；第八關投石車；第九關劉備並全角色解鎖；第十關是第一階段最終壓力關。
- 第一階段十關難度以起始資源、電腦能量、補給、AI 行動窗口與開場壓力逐步上升；僵屍出兵冷卻仍維持原本節奏，不用加快出兵速度來做難度。
- 修正擲石僵屍的投石顯示：投射物改成可見的旋轉石頭，避免投一次後看起來球不見。
- 寒冰趙雲增加藍色冷凍視覺處理，卡片、角色圖與場上單位會偏藍並帶冰光。
- 新增玩家進度：主選單與遊戲 HUD 會顯示等級、金幣、經驗值；勝利給較多金幣/經驗，失敗也給少量參與獎，並保存到瀏覽器 localStorage。
- 遊戲中新增「暫停 / 繼續」按鈕；暫停時戰場時間、AI、投射物與冷卻都會停止，棋盤上顯示「暫停中」遮罩。遊戲 HUD 已整理成最上方獨立控制列：關卡/資源、Lv/金幣/經驗與音樂/暫停/重開/回關頭都在同一排，卡片列獨立放下一排。
- 手機版遊戲畫面新增底部固定出角快捷列：卡片改成橫向滑動，不需要為了選角色在卡片區與棋盤間上下拉；側欄在手機版隱藏，棋盤下方預留空間避免被快捷列遮住。
- 僵屍方進攻初始腦已依十關重新拉曲線：第一關 320、第二關 400、第三關 480、第四關 560、第五關 650、第六關 725、第七關 800、第八關 875、第九關 960、第十關 1050；同時電腦三國守方起手資源逐關提高，讓進攻更有壓力，但僵屍出兵冷卻與出兵速度不加快。
- 背景音樂保留 Gimmy 已確認喜歡的 Asianoriental1 作為主畫面 BGM，正式主畫面路徑為 `assets/audio/bgm/01_main.ogg`；一進到遊戲後改播放 Gimmy 提供的新戰鬥 BGM `assets/audio/bgm/03_battle.mp3`。
- 音效仍用 WebAudio 即時合成；部署、射擊、命中、火焰、冰凍、爆炸/推車與一次性大招都有不同音效，一次性大招音效更強。
- 攻擊與技能增加動畫效果：角色入場/呼吸、攻擊時角色前衝、投射物閃爍、命中斬擊、冰凍/火焰特效、爆炸衝擊波與緩速冰光；龐統改為三列鳳火攻擊並顯示更強火焰/鳳火特效，馬超刺三格並顯示藍色穿刺軌跡，孔明全地圖攻擊會顯示全圖八卦/雷陣特效。

## 僵屍方角色

- 一般僵屍：便宜基本兵。
- 鐵甲僵屍：中階防禦。
- 獸之巨人：高血量重壓。
- 擲石僵屍：遠程投石。
- 跳躍僵屍：第二關新增，先快跑並跳過一名守方角色。
- 僵屍王將軍：強力菁英。
- 小丑僵屍：將軍級混亂術師，使用「亂陣狂笑」震懾同一路守方，造成傷害並讓守方短暫混亂停手。
- 炸彈小丑：將軍級爆破狂徒，被打敗後發動「終幕爆彈」，對自身周圍九宮格內守方造成爆破傷害。
- 屍旗巨魁：將軍級攻城巨屍，使用「破城屍槌」重擊前方守方，並震傷目標周圍九宮格內守方、短暫打斷行動。
- 投石車僵屍：將軍級攻城兵器，使用「烈焰轟石」遠距離轟炸同一路最密集防線，對目標周圍九宮格造成火焰濺射傷害。

## 未來武將角色庫

已存於 `assets/characters/future-generals/`，並已整合進三國守方卡片與角色介紹頁：

- 鬥神張飛：225 軍糧，高防禦/高攻擊，近戰反推一格，攻速慢。
- 寒冰趙雲：175 軍糧，遠程低傷、近戰高傷，命中緩速。
- 穿刺馬超：200 軍糧，三格穿刺群攻，顯示藍色刺擊軌跡。
- 百箭黃忠：200 軍糧，自己排/上排/下排三排射擊。
- 軍神孔明：250 軍糧，全地圖一次性高輸出，使用後消失。
- 火神龐統：175 軍糧，三列鳳火一次性高輸出，使用後消失。
- 關羽火焰將揮刀時保留原圖，短暫做向右前揮的翻轉/傾斜動畫，避免換圖突兀。
- 仁德劉備：300 軍糧，定時召喚上、前、下三隻可前進刀兵；已切割主圖與仁德治療、鼓舞士氣、雙股劍攻擊、守護之力四張戰鬥動作圖，召喚時會切換成鼓舞士氣動作。

## 未來商城 / 將軍能力

- 未來商城可使用目前已存在的金幣與經驗值，兌換或升級將軍能力。
- 劉備預留四個能力素材：仁德治世、昭烈之志、以德服人、匡扶漢室。
- 劉備四張戰鬥動作圖也已獨立保存，後續可在攻擊、治療、防守或技能施放時切換圖片。

詳細素材與能力 manifest：`assets/characters/future-generals/future-generals.json`。
