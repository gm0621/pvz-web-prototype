# 三國萌將守城：屍潮來襲｜網頁版遊戲原型

一個純前端 HTML/JavaScript 小遊戲：守城／攻城 → 第一季／第二季 → 選關。第一季十關依序解鎖，完成守城十關才開放第一季攻城；已通關關卡可重玩。主選單使用去背標題 LOGO 圖 `assets/brand/sanguo-zombie-title-logo-transparent.webp`。

## 第一季劇情試玩

- **蜀國篇．屍潮來襲**：十關守城＋十關攻城，皆有開場、通關與簡短失敗對話。攻城明示為「另一種可能」，不推翻守城結局。
- 讀開場時尚未建立新戰局；按「開始戰鬥」或「跳過，開始戰鬥」才開戰。已看過／跳過的段落不重播；續玩直接恢復暫停的戰鬥。
- 已解鎖關卡有「📖 劇情回看」，通關後可切換「通關後」。回看不開戰、不領獎、不改通關進度；×／Esc 可退出，未讀完的開場不會被標成已讀。
- 閱讀紀錄獨立存於本機瀏覽器的 `sgzStoryRead_v1`，不新增雲端資料欄位。換裝置可能再次播放；不影響雲端戰績。雲端未確認的勝利不播放勝利劇情。
- 第二季沿用既有流程，本次未增加第二季劇情、關卡或戰鬥機制。
- 大綱與第一關原稿：`docs/season1-story-outline-and-sample.md`；完整台詞：`docs/season1-story-script.md`。
- 修改原稿或 `scripts/build-season1-story.cjs` 後執行 `node scripts/build-season1-story.cjs`，同步產生 runtime 資料與完整台詞。驗證：`npm run test`。

## 玩法

- 流程：先選守城／攻城 → 選第一季／第二季 → 選已解鎖關卡 → 劇情（第一季）→ 戰鬥。
- 選關頁：第一階段總共十關。第一、二關共用原第一關白天圖但名稱不同；第三、四關也是白天新關；第五、六關由原第二關夜戰拆成兩關；第七、八關由原第三關攻城拆成兩關；第九、十關由原第四關決戰拆成兩關。每張關卡卡片已改成較有劇情的戰場說明，並新增獨立「出場人物」區塊，列出該關重點守方與僵屍角色。
- 第一關｜草坪試煉：入門 1，白天基礎教學，只開伏兵、軍糧官、盾將、蜀軍弓兵，以及一般/鐵盔小兵。
- 第二關｜軍糧小徑：入門 2，仍使用白天草坪圖，加入關羽火焰將、巨槌阿蠻與飛石阿投。
- 第三關｜白日突圍：普通 1，白天新關，解鎖寒冰趙雲與蹦蹦飛屍。
- 第四關｜前線演武：普通 2，白天新關，解鎖火神龐統、穿刺馬超與白髮屍王。
- 第五關｜鐵甲夜襲：進階 1，由原第二關拆出，進入夜戰並解鎖百箭黃忠、鈴鐺丑屍。
- 第六關｜夜半奔襲：進階 2，由原第二關拆出，解鎖鬥神張飛與爆爆桶屍。
- 第七關｜火石攻城：將軍 1，由原第三關拆出，解鎖軍神孔明與屍旗大胖。
- 第八關｜烈焰破陣：將軍 2，由原第三關拆出，烈焰屍車正式登場。
- 第九關｜群魔決戰：決戰 1，由原第四關拆出，仁德劉備加入，雙方全角色開放。
- 第十關｜屍潮終局：決戰 2，由原第四關拆出，是第一階段最終壓力關。
- 三國守方：部署蜀軍弓兵、軍糧官、盾將、伏兵、關羽火焰將防守戰線；每一路有一台最後防線推車，僵屍碰到時會衝整排並清掉該路僵屍。
- 僵屍方：派出僵屍、吃掉守方角色直接獲得腦資源；電腦三國守方也有推車，每一路第一次被突破會先清掉整路僵屍；如果腦資源不足且場上無僵屍可繼續推進就輸。
- 資源不會掉在畫面上，避免誤以為要點擊收集；軍糧/腦只會在 HUD 數字更新。
- 叫出守方角色或僵屍都有冷卻時間，卡片底部會顯示冷卻進度。遊戲中角色卡已改成小卡橫向排列，讓棋盤更大、點選距離更短；可先點卡片再點格子，也可以把卡片拖曳到格子上直接叫出角色。暫停時卡片會放大並顯示角色說明，方便玩家慢慢看能力。
- 關卡的電腦出兵、防線與補能量節奏會隨機變化，不會每次完全相同；新版電腦會依照場上哪一路壓力最大來選擇派兵/補防，不再完全亂丟。
- 電腦強單位有延後出場門檻：守城戰不會一開始就派巨槌阿蠻、飛石阿投、蹦蹦飛屍、白髮屍王或後續將軍級攻城單位；進攻戰的電腦守方也會先鋪軍糧官、盾將、弓兵等基本防線，再逐步使用關羽、趙雲、張飛、孔明、劉備等強武將。守城戰的電腦僵屍方初始腦力已提高，但出兵節奏改成前 15 秒較慢、中段恢復、後段才加快；出兵路線會隨機從前三個破口候選挑選，優先找守軍較少、推車已用掉、或有機會攻破的薄弱路線，不再一直壓同一線。
- 已加入三國守方 PNG/WebP 素材與新版僵屍方 PNG/WebP 素材；關羽的角色介紹、頭像、卡片與戰場單位統一使用最新指定的 Q 版青龍偃月刀／綠焰龍魂圖。僵屍方新增始皇屍帝・嬴政，採最新指定的黑紅冕旒亡魂圖並水平鏡像，普通召喚秦俑屍兵，機率技能在三路召喚玄甲禁軍。
- 鈴鐺丑屍是將軍級混亂術師：綠髮、鈴鐺尖帽與骷髏權杖讓人一眼認出屍潮中的怪笑指揮官；能力「亂陣狂笑」會震懾同一路守方，造成傷害並讓守方短暫混亂停手，適合在防線密集時撕開破口。
- 爆爆桶屍是將軍級爆破狂徒：背滿炸藥、火藥桶與燃燒導火線，衝進防線就準備把自己變成最後煙火；能力「終幕爆彈」會在被打敗時自爆，對自身周圍九宮格內守方造成重創，逼三國守方分散站位。
- 屍旗大胖是將軍級攻城巨屍：背負「屍」字戰旗，肩上屍兵敲鼓催戰，以巨大拳頭正面碾開防線；能力「破城屍槌」會重擊前方守方，並震傷目標周圍九宮格內守方、短暫打斷行動，是屍潮最後壓線的主將。
- 烈焰屍車是將軍級攻城兵器：木製戰車綁滿鐵刺、骷髏旗與紅色戰布，車上僵屍操縱燃燒巨石轟向城牆；能力「烈焰轟石」會遠距離鎖定同一路防線最密集處，砸下火焰巨石並對目標周圍九宮格造成濺射傷害。
- 首頁新增「角色介紹 / 能力圖鑑」頁，可切換查看三國守方與僵屍方，每個角色都有圖片、消耗與能力說明；角色卡片與圖鑑已改成由弱到強排序，方便從基礎兵種一路看到將軍級角色。角色介紹頁現在會顯示全部角色，不再只顯示目前關卡已解鎖的幾張；未解鎖角色會標示第幾關解鎖，每張角色卡會直接顯示 HP 生命值。角色介紹卡片可點擊打開詳細彈窗，展示特殊技能、影響範圍九宮格示意，以及生命值 HP、近戰攻擊力、遠戰/技能攻擊力、防禦力、攻擊範圍、移動速度、攻擊速度與卡片冷卻。

## Supabase Auth 雲端帳號設定

此版本提供 Email/密碼註冊登入、忘記密碼、重寄驗證信、修改 Email、修改密碼、登出此裝置與登出所有裝置。登入後右上角顯示玩家名稱，點擊可管理玩家資料與帳號安全；未登入仍可使用 localStorage 本機存檔。

管理者第一次設定：

1. 建立 Supabase project，並在 Auth 開啟 Email provider；若要使用 Google 登入，再開啟 Google provider 並設定 OAuth Client ID / Secret。
2. 在 Supabase Auth URL 設定加入 GitHub Pages 網址：`https://gm0621.github.io/pvz-web-prototype/`；Site URL 與 Redirect URLs 都加入此網址。
3. 先執行 `supabase/sgz_profiles.sql` 建立基本 profile 表，再執行 `supabase/migrations/202609020001_production_foundation.sql`。
4. migration 會建立原子 active-device lock、30 秒 heartbeat、120 秒逾時、`save_version` optimistic lock、Realtime 接管通知、商城 catalog、交易 audit、對戰紀錄、頭像 Storage bucket 及購買／裝備／外觀／角色升級／戰利品 RPC。
5. 前端只放 anon publishable key；service role key 不可放在前端或 Git。

資料安全：一般 profile 儲存 RPC 不接受客戶端修改 `gold/xp/level/characterLevels/inventory/highestLevel/completedLevels`；這些欄位只能由專用 `SECURITY DEFINER` RPC 在資料列鎖定後修改。所有 RPC 都以 `auth.uid()` 定位玩家，並驗證目前 active device。商城扣款與物品發放在同一個 PostgreSQL transaction 完成，並記錄於 `sgz_economy_transactions`。

對戰獎勵不接受前端傳入勝敗值，只接受伺服器核發且達到關卡最低時間的單次 match completion；角色 XP 每場最多指定一名已存在角色。由於戰鬥模擬仍在瀏覽器執行，這可防止直接偽造 `p_won` 與高速重複領獎，但若要做到競技遊戲等級的完整反作弊，仍需把戰鬥模擬或 replay validator 搬到伺服器。

## 僵屍方角色

- 赤巾小屍：便宜基本兵。
- 鐵盔小兵：中階防禦。
- 巨槌阿蠻：高血量重壓。
- 飛石阿投：遠程投石。
- 蹦蹦飛屍：第二關新增，先快跑並跳過一名守方角色。
- 白髮屍王：強力菁英。
- 鈴鐺丑屍：將軍級混亂術師，使用「亂陣狂笑」震懾同一路守方，造成傷害並讓守方短暫混亂停手。
- 爆爆桶屍：將軍級爆破狂徒，被打敗後發動「終幕爆彈」，對自身周圍九宮格內守方造成爆破傷害。
- 屍旗大胖：將軍級攻城巨屍，使用「破城屍槌」重擊前方守方，並震傷目標周圍九宮格內守方、短暫打斷行動。
- 烈焰屍車：將軍級攻城兵器，使用「烈焰轟石」遠距離轟炸同一路最密集防線，對目標周圍九宮格造成火焰濺射傷害。
