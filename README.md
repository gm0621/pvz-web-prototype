# 萌將守城戰｜網頁版遊戲原型

一個純前端 HTML/JavaScript 小遊戲原型：開頭可選三國守方或僵屍方，接著進入獨立選關頁，可直接跳第一關或第二關測試。

## 玩法

- 流程：先選陣營 → 進入選關頁 → 直接開始第一關或第二關。
- 選關頁：提供「第一關｜草坪試煉」與「第二關｜鐵甲夜襲」，第二關可直接跳關測試，不需要先通過第一關。
- 第一關｜草坪試煉：基本隨機攻防，熟悉推車、冷卻與電腦能量。
- 第二關｜鐵甲夜襲：夜晚場景、較高難度，鐵甲僵屍、擲石僵屍、獸之巨人與跳躍僵屍更常出現，電腦能量補充更快，防線更厚。
- 三國守方：部署蜀軍弓兵、軍糧官/小軍師、盾將、伏兵、關羽火焰將防守戰線；每一路有一台最後防線推車，僵屍碰到時會衝整排並清掉該路僵屍。
- 僵屍方：派出僵屍、吃掉守方角色直接獲得腦資源；電腦三國守方也有推車，每一路第一次被突破會先清掉整路僵屍；如果腦資源不足且場上無僵屍可繼續推進就輸。
- 資源不會掉在畫面上，避免誤以為要點擊收集；軍糧/腦只會在 HUD 數字更新。
- 叫出守方角色或僵屍都有冷卻時間，卡片底部會顯示冷卻進度。
- 關卡的電腦出兵、防線與補能量節奏會隨機變化，不會每次完全相同。

## 僵屍方角色

- 一般僵屍：便宜基本兵。
- 鐵甲僵屍：中階防禦。
- 獸之巨人：高血量重壓。
- 僵屍王將軍：強力菁英。
- 擲石僵屍：遠程投石。
- 跳躍僵屍：第二關新增，先快跑並跳過一名守方角色。
