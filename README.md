# 花園攻防戰｜網頁版遊戲原型

一個純前端 HTML/JavaScript 小遊戲原型：開頭可選植物方或僵屍方，接著進入獨立選關頁，可直接跳第一關或第二關測試。

## 玩法

- 流程：先選陣營 → 進入選關頁 → 直接開始第一關或第二關。
- 選關頁：提供「第一關｜草坪試煉」與「第二關｜桶盔夜襲」，第二關可直接跳關測試，不需要先通過第一關。
- 第一關｜草坪試煉：基本隨機攻防，熟悉推車、冷卻與電腦能量。
- 第二關｜桶盔夜襲：夜晚場景、較高難度，鐵桶/路障更常出現，新增撐桿跳僵屍，電腦能量補充更快，防線更厚。
- 植物方：放置植物、防守草坪；每一路有一台最後防線推車，僵屍碰到時會衝整排並清掉該路僵屍。
- 僵屍方：派出僵屍、吃掉植物直接獲得腦資源；電腦植物方也有推車，每一路第一次被突破會先清掉整路僵屍；如果腦資源不足且場上無僵屍可繼續推進就輸。
- 資源不會掉在畫面上，避免誤以為要點擊收集；陽光/腦只會在 HUD 數字更新。
- 叫出植物或僵屍都有冷卻時間，卡片底部會顯示冷卻進度。
- 關卡的電腦出兵、防線與補能量節奏會隨機變化，不會每次完全相同。
- 已加入 11 個第五版「參考圖角色卡」風格 SVG 素材，放在 `assets/characters/`；角色改成無背景、簡潔黑線、柔和手繪陰影、卡片人物介紹感。豌豆射手改為圓形豌豆嘴放在嘴巴位置，避免外接管不自然。

## 本機開啟

直接打開 `index.html` 即可遊玩。
