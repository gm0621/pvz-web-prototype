# 花園攻防戰｜網頁版遊戲原型

一個純前端 HTML/JavaScript 小遊戲原型：開頭可選植物方或僵屍方，並可遊玩隨機第一關。

## 玩法

- 植物方：放置植物、防守草坪；每一路有一台最後防線推車，僵屍碰到時會衝整排並清掉該路僵屍。
- 僵屍方：派出僵屍、吃掉植物直接獲得腦資源；如果腦資源不足且場上無僵屍可繼續推進就輸。
- 資源不會掉在畫面上，避免誤以為要點擊收集；陽光/腦只會在 HUD 數字更新。
- 叫出植物或僵屍都有冷卻時間，卡片底部會顯示冷卻進度。
- 第一關的電腦出兵、防線與補能量節奏會隨機變化，不會每次完全相同。

## 本機開啟

直接打開 `index.html` 即可遊玩。
